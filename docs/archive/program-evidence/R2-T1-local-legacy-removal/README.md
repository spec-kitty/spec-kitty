# R2-T1 Historical Program Evidence

This directory preserves two immutable historical program documents.
The original bundle described R2-T1 retirement scope and commit attribution.
It was not a mission record and had no mission identity metadata.
Moving it outside the immediate mission corpus preserves that distinction.

## Original Documents

- [Deletion manifest](deletion-manifest.md): frozen historical module scope.
- [Commit history notes](commit-history-notes.md): historical attribution correction.

Both documents retain their original bytes and file modes, including legacy
terminology. Their contents are historical evidence, not current instructions
