## Method and tools

Subjects: core `spec-kitty` at `5c4fc5a79d` (head; extracted with `git archive`, because the local checkout is at a different commit) and `spec-kitty-charter` at `06cdfbe948` (head). All checks ran in `ws-G2/` scratch copies.

Four checks were written (stored as `.txt` in `evidence/G2/`):

- `check_g2_pyimports.txt`: an AST import extractor for core `src/`. It covers module-level and function-local imports, relative imports and literal-string `import_module`, `__import__` and `find_spec` calls, and flags `TYPE_CHECKING`. It found 27,569 import-name rows in 1,490 files.
- `check_g2_core.txt`: I1 to I4 over that table. It parses the two allowed-exception ledgers from `tests/architectural/test_layer_rules.py` and compares against `charter_activation_boundary_baseline.yaml` and `charter_offering_public_surface.yaml`.
- `check_g2_core_i5.txt`: owned-state write sites, in two tiers (function co-location, then module), followed by manual adjudication.
- `check_g2_java.txt`: Gradle `project()` dependencies, Java imports and fully qualified references, ring classification, CLI patterns and file-system write APIs, plus the documented module table in `docs/architecture/hexagonal-service.md`.

Reused gates: as a cross-check I ran `test_layer_rules.py`, `test_status_events_writes_gate.py`, `test_status_module_boundary.py`, `test_runtime_charter_activation_boundary.py` and `test_mission_runtime_surface.py` (core), and `HexagonalArchitectureTest` through `verifyAll` (charter, 99/99).

Tools: CPython 3.13.18 (checks), uv 0.11.32, hatchling via `uv build`, pytest 9.0.3 under the dev venv (CPython 3.11.15), Gradle 9.8.1 on Temurin 25.0.5, GNU grep.

## Deviations

- Core I1/I3: "new" is judged against recorded ledgers, not against an earlier revision. The brief says "relative to a recorded baseline", and only these ledgers exist. At the second-package level no baseline exists, so I report the count and mark it as not evaluable.
- Core I2: kernel, glossary, runtime and specify_cli have no declared public surface. I used the underscore-prefix convention for them and labelled the result as convention-based.
- Core I5: the function-level heuristic did not find the owners' own writes, because the path is passed as a parameter. I added a module tier, adjudicated candidates by reading the code, and cross-checked against the recorded allowlists. Seven candidate functions in 6 modules were left unadjudicated.
- Core I6: the named own-check test used `--noconftest -o addopts=` after the conftest collection hook was killed twice by the out-of-memory killer (exit 137). The later full-conftest gate run covers the conftest path.
- Charter I6: four `verifyAll` attempts. Two were lost when the Gradle daemon was killed (host memory pressure, then a session interruption). One failed because a source archive has no `.git` (`contracts:checkPacksChangelog` reads git tags). The fourth ran in a `git clone --shared` with `--max-workers=2` and a 1536 MB heap, and succeeded.

## Blocked
