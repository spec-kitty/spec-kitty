# Logged Out on a Connected Teamspace (Removed)

The teamspace login and recovery flow this page described, and the `spec-kitty auth` and `spec-kitty sync` commands it relied on, were removed from the open-core CLI in [#6164](https://github.com/spec-kitty/spec-kitty/issues/6164). The code is preserved in the `spec-kitty/event-router` repository. No local Mission command needs a login.

See [Team Kitty](../context/team-kitty.md) for what was removed and what stays.
