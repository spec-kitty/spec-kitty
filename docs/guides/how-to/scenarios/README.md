# Scenario Walkthroughs

End-to-end, role-based walkthroughs showing how real teams and solo developers run Spec Kitty.

- [Solo Developer Workflow](solo-developer-workflow.md) — Iterate quickly as a solo developer using Spec Kitty with a single AI agent while keeping systematic tracking and status visibility.
- [Agency Client Transparency Workflow](agency-client-demo.md) — Give agency clients read-only visibility into Spec Kitty mission progress through status reports without exposing any source code.
- [Parallel Implementation Tracking](parallel-implementation-tracking.md) — Track several agents implementing a roadmap in parallel and give leadership continuous visibility through Spec Kitty status views and activity logs.
- [Multi-Agent Mission Development](multi-agent-mission-development.md) — Orchestrate a multi-agent team of Claude, Gemini, and Cursor to deliver a complex mission end to end with Spec Kitty work packages and human review.
- [Parallel Mission Development with Worktrees](worktree-parallel-missions.md) — Develop three or more Spec Kitty missions at once using git worktrees to avoid branch-switching churn and preserve each mission's IDE state.
- [Claude and Cursor Collaboration](claude-cursor-collaboration.md) — Combine Anthropic Claude for planning with Cursor for implementation inside Spec Kitty worktrees while keeping the kanban workflow and guardrails intact.
- [Charter-Driven Quality Gates](charter-driven-quality.md) — Enforce consistent code, testing, and documentation standards across every mission by defining a project charter Spec Kitty commands apply automatically.
- [Deep Research Mission Workflow](research-mission-example.md) — Run systematic, evidence-based research investigations with Spec Kitty's research mission template, from switching modes to collecting and citing findings.
