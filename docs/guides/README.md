# Guides

End-user documentation for Spec Kitty. Guides come in two Divio flavors:

- **[Tutorials](tutorials/README.md)** — learning-oriented walkthroughs for newcomers.
- **[How-To Guides](how-to/README.md)** — task-oriented recipes grouped by concern.

New here? Start with **[When to Use Spec Kitty Modes](when-to-use-modes.md)** to pick the lightest path for your work, then jump into a tutorial.

## How-To concerns

- [Installation & Upgrade](how-to/installation/README.md) — Install, upgrade, repair, and uninstall the Spec Kitty CLI and project across macOS, Linux, and Windows.
- [AI Agent Harnesses](how-to/harnesses/README.md) — Set up and run Spec Kitty inside each supported AI coding agent, plus post-edit lint hooks.
- [Run a Mission](how-to/missions/README.md) — Author and drive a mission from specification through plan, tasks, implementation, review, and merge.
- [Governance & Doctrine](how-to/governance/README.md) — Set up a project charter, synthesize doctrine, manage the glossary, and run governed missions.
- [Parallel & Multi-Agent Work](how-to/collaboration/README.md) — Coordinate multiple agents, worktrees, orchestrators, and dependencies across parallel work packages.
- [Status & History](how-to/monitoring/README.md) — Check mission progress from the CLI and review your git operation history.
- [Recovery & Troubleshooting](how-to/recovery/README.md) — Recover from implementation crashes and interrupted merges, and troubleshoot merge failures.
- [Scenario Walkthroughs](how-to/scenarios/README.md) — End-to-end, role-based walkthroughs showing how real teams and solo developers run Spec Kitty.
