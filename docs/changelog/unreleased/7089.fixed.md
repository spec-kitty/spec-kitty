- **The pre-review regression gate is usable again: a pinned `pre_review_test_scope` parses, and the budget matches the scope the gate runs** (#6865). **Before:** every `for_review` move on a repo that declares a whole-suite review command (this repo's `make test-fast`) was refused with `timed_out` at the scoped 300 s default; and the recovery the gate advertised — a bounded `pre_review_test_scope` in the WP frontmatter — made the WP unreadable, so the subtask-roster guard failed. **After:** the key is part of the strict WP model, a whole-declared-command run is bounded by a whole-command budget (1,200 s, or your declared `review.test_timeout_seconds`), a pinned target list keeps the scoped default, and both refusals name the scope shape, the executed command, the policy metadata and the recovery. No gate is weakened.
