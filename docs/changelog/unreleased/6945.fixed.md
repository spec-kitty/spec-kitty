- **`charter activate`/`deactivate --cascade` now start from the artifact you named, however you spelled it** (#6433). **Before:** passing a `<kind>:<id>` URN or a normalized directive id (`24`) activated or deactivated the right artifact, then silently skipped the cascade: no `Cascade-activated:` line, and on deactivate no `Skipped (shared artifact):` line either, because the cascade source resolved through a separate stem<->id path that refused those spellings. **After:** the source resolves through the same identity index as the runtime gate, so a file stem, a declared id, a URN and a normalized directive id reach the same DRG node; a genuinely unknown token still yields no source. `resolve_artifact_urn` and `resolve_config_id` now answer from that index, so a file stem, a declared id, a URN or a normalized directive id resolves the same way on every surface (a directive id that no file name can represent still refuses in the resolver, as before). `<kind>:<id>` URNs and the normalized form (e.g. `24`) are now accepted wherever a stem or declared id is (compile/resynthesis preflight, interview selection), which previously refused or warned.
