- **A Mission with no recorded planning commit can be landed again** (#7209, #7210). **Before:** `consolidate --skip-lanes` on a Mission with no `lanes.json` refused every approved work package with `EVIDENCE_WINDOW_UNCOMPUTABLE`, and so did a Mission whose `lanes.json` predates the planning pin; the remedy the refusal named, re-running `finalize-tasks`, left the pin empty. **After:** the window starts at a base read from git: for `--skip-lanes`, the parent of the first commit on the target branch that added the Mission's `meta.json`; for an older `lanes.json`, plain `finalize-tasks` records the parent of the first commit that added the Mission's `tasks/WP*.md` and reports it as `derived`. When no base can be derived, the refusal says so and names what to do. **What to do:** for an older Mission that refuses, run `spec-kitty agent mission finalize-tasks` without flags, then re-run.
