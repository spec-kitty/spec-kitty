- **`docs.spec-kitty.ai` is now built with doc-kitty instead of DocFX, and every deploy is checked on the live site** (#6938, #2361, epic #6100). **Before:** a push to `main` published the DocFX build, and nothing checked what Pages actually served after a deploy. **After:** `docs-pages.yml` publishes the build of the shared `docs-site-build.yml`, so `main` only deploys a site built by the definition the required `docs-site` pull-request gate runs. A `smoketest` job then runs `scripts/docs/site_live_probe.py` against `https://docs.spec-kitty.ai`, and a mismatch turns the run red. The dispatch-only canary is retired, and the hand-written `docs/llms.txt` is deleted because the site generates `/llms.txt`. Rollback is reverting the cutover pull request, which restores the DocFX deploy. ADR 2026-10-31-1 carries an amendment.
