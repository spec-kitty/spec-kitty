- **`spec-kitty consolidate` advances the target past a Mission directory that holds only the decisions lock** (#7746). **Before:** when the repository-root checkout's ignored `kitty-specs/<mission>/` (or `decisions/`) held nothing but the persistent `decisions/index.json.lock`, `git status` reported the whole directory as one ignored entry, the guard judged it as a directory that overlaps the incoming Mission files, and `consolidate` refused to advance the target and rolled back. **After:** an ignored directory that overlaps the target tree is judged file by file, so the lock (which collides with nothing) no longer blocks the advance. An ignored file that would be overwritten still refuses, and the refusal still names its directory.
