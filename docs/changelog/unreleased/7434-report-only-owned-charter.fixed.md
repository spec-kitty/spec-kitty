- **`spec-kitty agent mission record-analysis --report-only` in an owned checkout records the owned charter** (#7434). **Before:** it recorded the repository-root charter's digest, so `next` read the fresh report as stale whenever the two charters differed. **After:** it binds and checks the owned checkout's charter, as the full recorder and `next` do, and no longer refuses for uncommitted changes to the repository-root charter.
