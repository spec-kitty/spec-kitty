- **An uncommitted lifecycle record no longer blocks dirty-state gates** (#7346). **Before:** when a `kitty-ops/lifecycle/<ULID>.json` record stayed uncommitted, for example a closure `spec-kitty doctor ops --close-stale` could not commit (skipped, or refused on a protected branch), it counted as uncommitted work, so `accept`, `record-analysis` and the other gates that check for a dirty checkout refused on it. **After:** the record counts as Spec Kitty's own bookkeeping, as an uncommitted `kitty-ops/<ULID>.jsonl` Op record already did. Any other file under `kitty-ops/lifecycle/` still counts as uncommitted work. As for Op records, `consolidate`'s cleanup no longer keeps a lane or coordination checkout for an uncommitted lifecycle record, so removing that checkout discards the record.
