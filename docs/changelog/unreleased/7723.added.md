- **`spec-kitty doctor command-files` and `doctor skills` report copies left under an agent's previous user-global root** (#7723). When `CLAUDE_CONFIG_DIR` (or another documented config-root variable) moves an agent's user-global commands and skills away from `~/.claude`, the files Spec Kitty wrote under `~/.claude/commands` and `~/.claude/skills` stay behind. Both doctors now list the ones Spec Kitty provably wrote (today's render, an older release's version-marked command file, a skill render that shipped for that exact path, or a file Spec Kitty's own global asset inventory records with exactly these bytes) with an `rm` line you can run; nothing is written or deleted, and files Spec Kitty cannot prove it wrote are not listed. `doctor command-files --json` adds them as rows with `"severity": "info"` and `"issue": "leftover copy under the previous user-global root"`; `info` rows never change the exit code. `doctor skills --json` adds an `old_root_leftovers` list that does not change `ok`. Opt-in removal is tracked in #7758.
