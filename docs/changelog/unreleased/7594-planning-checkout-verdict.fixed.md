- **`setup-plan` and `check-prerequisites` give the same checkout verdict** (#7594). **Before:** for a Mission created without `--topology`, the two commands reported opposite `branch_matches_target` values for the same checkout, before and after `finalize-tasks` settled the Mission, which stopped the tasks step. `setup-plan` also reported the minted topic branch as `target_branch`, and `check-prerequisites` read the root checkout's branch from any worktree. **After:** both commands report the branch of the checkout they run in as `current_branch`, the Mission's landing branch as `target_branch`, and the branch its planning artifacts are committed to as `branch_context.expected_checkout_branch`. That branch is the topic branch until the Mission lands, also after settlement, so from the repository root checkout of a settled Mission both now report `false` and name the topic branch.
