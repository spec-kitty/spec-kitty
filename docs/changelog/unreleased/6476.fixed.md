- **The generated Claude plugin wrapper now runs the CLI on a machine that only has `uv`** (#6476). **Before:** with no `spec-kitty` on PATH the wrapper fell back to `uvx "spec-kitty-cli==<version>"`, which asks uvx for an executable named after the distribution; the distribution ships only `spec-kitty`, so it exited 1 and every bundled skill failed. Any PATH `spec-kitty` was used, whatever its version. **After:** both wrappers run `uvx --from "spec-kitty-cli==<version>" spec-kitty`, use a PATH CLI only when its version is inside the bundle's `<major>.<minor>` series, and — when the pinned build version is not on PyPI — retry with `spec-kitty-cli>=<version>,<<next minor>`. The remedy names `uv tool install` / `pipx install`, not `pip install`. See [the plugin install guide](../guides/how-to/installation/install-claude-code-plugin.md#how-the-runtime-wrapper-works).
