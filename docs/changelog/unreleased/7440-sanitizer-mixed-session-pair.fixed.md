- **A naive/aware session timestamp pair no longer breaks event writes** (#7440). **Before:** `sanitize_event_for_log` subtracted a naive from a timezone-aware `session_started_at` / `session_ended_at` and raised `TypeError`, which aborted the status write and lost the decision event. **After:** a mixed pair is treated as malformed: both timestamps are dropped and no `session_duration_s` is emitted.
