- **`spec-kitty consolidate --dry-run` under squash runs the same content check as the real squash run** (#7244). **Before:** the dry run always ran the merge strategy's per-commit check, so a mission branch commit whose content the squash leaves unchanged on the target was reported as `UNATTRIBUTABLE_CONTENT_FORECAST`, while the real squash run landed the Mission. **After:** under squash the dry run checks the squashed tree the way the real squash run does (each changed file must carry content an approved work package wrote); `--strategy merge` and `--strategy rebase` keep the per-commit check. A check that cannot be completed is reported as `CLAIM_REFUSED_FORECAST`. **What to do:** nothing.
