- **`spec-kitty consolidate --dry-run` under squash no longer refuses a mission branch commit the real squash run lands** (#7244). **Before:** the dry run always ran the merge strategy's per-commit check, so a mission branch commit whose content the squash leaves unchanged on the target was reported as `UNATTRIBUTABLE_CONTENT_FORECAST`, while the real squash run landed the Mission. **After:** under squash the dry run checks the mission branch's squashed tree the way the real squash run does (each changed file must carry content an approved work package wrote), and still scans lane commits one by one, because the preview does not fold lanes in yet; `--strategy merge` and `--strategy rebase` keep the per-commit check. A check that cannot be completed is reported as `CLAIM_REFUSED_FORECAST`. **What to do:** nothing.
