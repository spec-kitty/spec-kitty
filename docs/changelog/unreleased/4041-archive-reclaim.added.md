- **`spec-kitty archive reclaim <mission>` removes the coordination worktree, branch and marker an archived Mission still holds** (#4041). It deletes the branch only when the Mission records its landing and the branch has nothing beyond the coordination tip that landing recorded, and refuses otherwise with a `RECLAIM_*` code and a remedy. `spec-kitty archive create` prints the reclaim command when the Mission still holds a coordination marker.
