- **`spec-kitty consolidate` no longer treats history from before a Mission was created as Mission work** (#7560). **Before:** on a fork whose local target lacked the commit the Mission branch was cut from, a plain run reported that older history as un-attributable, and `--dependency-ref` refused with `DEPENDENCY_REF_COVERS_MISSION_WORK`. **After:** the Mission base is read from `meta.json` `mission_base_sha`, recorded from the target's start point when the Mission branch is created and used only when it is a full commit id on the history the Mission started from; history below it counts as already on the target, and a note names the base. A base derived from the scaffold commit (Missions created before this release) exempts nothing, because it cannot be told apart from Mission work on the branch; record `mission_base_sha` to opt in. Work the Mission did after its base refuses exactly as before.
