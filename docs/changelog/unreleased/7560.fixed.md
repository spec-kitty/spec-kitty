- **`spec-kitty consolidate` no longer treats history from before a Mission was created as Mission work** (#7560). **Before:** on a fork whose local target lacked the commit the Mission branch was cut from, a plain run reported that older history as un-attributable, and `--dependency-ref` refused with `DEPENDENCY_REF_COVERS_MISSION_WORK`. **After:** the Mission base is read from `meta.json` `mission_base_sha` (recorded when the Mission branch is created; used only when it is a full commit id on the history the Mission started from) or derived as the parent of the commit that first added `kitty-specs/<slug>/`; history below it counts as already on the target, and a note names the base. When no base can be established, the old bound applies and the note says why. Work the Mission did after its base refuses exactly as before.
