- **`spec-kitty accept` commits its record on the Mission branch of a settled default Mission** (#7550, #7544). **Before:** with the Mission settled to `lanes_with_coord` and the repository root checkout on its unprotected target, `accept` wrote the record into the coordination worktree's `meta.json`, then staged it from the root checkout, where `.worktrees/` is git-ignored: it stopped with a raw traceback, and `accepted_from_commit` named the target's tip. **After:** the record and the residual acceptance commit go through the placement-aware commit seam (also with `--owned-checkout`) onto the branch checked out where the record is written; `accepted_from_commit` is that branch's tip; a failed record commit refuses with `ACCEPT_RECORD_COMMIT_FAILED`, naming the cause and the remedy, while a failed follow-up `accept_commit` stamp only warns. The `status_phase` stamp is unchanged. Like every other Spec Kitty bookkeeping commit, the acceptance commits are now unsigned (they used to honor `commit.gpgsign` on an unprotected branch).
