- **`spec-kitty consolidate` and `spec-kitty doctor workspaces --prune` remove the lanes of a squash-landed Mission** (#7747). **Before:** a `lanes_with_coord` lane carried older copies of Mission files it never wrote, or lines a later lane rewrote, so cleanup kept every lane with `NOT_LANDED_ON_NAMED_REMOTE` and the printed `doctor workspaces --prune` remedy refused them with `CONTENT_NOT_ON_PRIMARY`. **After:** one landing proof sets aside the Mission files a lane never authored and judges `status.json` by its status log; `consolidate` also proves each lane landed through the Mission branch before tearing it down; `accept --mode pr` and `doctor workspaces` use the same proof. A lane whose own work did not land is still kept. After a push, `doctor workspaces` still keeps a lane whose lines a later lane rewrote.
- **A lane with no usable landing proof is kept, never deleted** (#7325). **Before:** a lane with no landing proof, an empty reconciliation PASS anchor, a missing worktree or no nameable tip went to the older remover, which could delete a branch holding unlanded commits. **After:** it is kept with `LANDING_PROOF_UNAVAILABLE`, its branch untouched, and the remedy compares content with `git diff` (or names the lane-tip ref when the branch is gone).
