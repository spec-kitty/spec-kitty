- **`charter context` no longer advertises action-critical charter sections a consumer charter does not have** (#6968). **Before:** `charter context --action implement` (and `review`) emitted `Run: … --include section:terminology-canon`, `…-code-review-checklist` and `…-regression-vigilance` even when `charter.md` carried none of them, and each fetch answered "This charter has not yet authored … Add one", so an agent was told that loading a placeholder was action-critical. **After:** only headings the active charter resolves are advertised, each with its verbatim body and recovery stanza; an absent, empty or fence-masked heading is not, and the block header is omitted when nothing resolves. Output for a project that authors them is unchanged, and an explicit `--include section:<slug>` still returns the honest placeholder. **What to do:** nothing.
