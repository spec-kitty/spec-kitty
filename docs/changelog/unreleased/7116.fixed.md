The repair refused: the `2.0.6` sweep reported `wrote baseline meta.json` and wrote nothing, kept reporting the project as needing repair, and the successor sweep advised `git checkout --` on a path git does not track. A stray `/tmp/.git` was enough. **After:** an anchor is a `.git` pointer file or a `.git` directory that holds `HEAD`; the walk continues past anything else, and an unreadable anchor still refuses, so no second identity is minted over tracked history. **What to do:** nothing.
