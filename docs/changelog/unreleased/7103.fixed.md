- **`spec-kitty accept --owned-checkout` checks the owned Mission's implementation** (#7103, #7099). **Before:** a real, independently reviewed implementation could be refused because evidence checks read ownership and topology from the primary checkout; stale primary ownership could also hide missing owned ownership. **After:** evidence checks use the validated owned-checkout authority, while missing implementation, self-review, and missing ownership still fail closed. Owned self-review refusals also use the owned topology's `SINGLE_BRANCH_REVIEW_NOT_INDEPENDENT` code, even with a stale primary topology. Coordination without an owned checkout keeps PRIMARY authority.
