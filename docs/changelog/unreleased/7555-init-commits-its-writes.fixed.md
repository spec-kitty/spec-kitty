- **`spec-kitty init` commits the files it writes** (#7555). **Before:** inside a git repository `init` wrote `.kittify/`, the agent directories, `.gitignore` and `.gitattributes` and committed none of them, so the first gated command saw them as uncommitted work and the agent committed them by hand. **After:** when the directory is the top of a git repository with at least one commit, `init` commits exactly the files it wrote in one commit (`chore: initialize spec-kitty project`), the same way `spec-kitty upgrade` commits its changes; files that were already uncommitted stay out, `--no-commit` skips the commit, and on a repository with no commit yet `init` names the first commit to make. `init` still never runs `git init`.
