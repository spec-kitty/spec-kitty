- **Upgrade refusals name Git's repair class instead of an unusable file restore** (#7131). **Before:** unreadable Git state could get an unproven "tracked" label and a `git checkout --` remedy that could not succeed. **After:** `TRACKED_META_UNAVAILABLE` still refuses without minting identity or writing metadata or trust settings. The notice distinguishes repository layout/environment failures (`git status`), ownership refusals (an operator decision scoped to one path, never wildcard `safe.directory`), and committed-content access failures (`git fsck` can help diagnose them). A path merely containing `safe.directory` no longer masquerades as an ownership refusal; modern/legacy diagnoses and Git's exception hint remain recognized. Raw Git stderr is not copied into these notices. **What to do:** repair the reported cause, then re-run the upgrade.
