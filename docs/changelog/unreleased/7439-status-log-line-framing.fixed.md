- **Status event-log rows are framed only at line breaks** (#7439). **Before:** the event-log readers split rows with `str.splitlines()`, so a row whose text held U+2028, U+2029 or U+0085 was cut into two undecodable halves, and a row with an integer over 4300 digits or very deep nesting escaped as a raw `ValueError` or `RecursionError`. **After:** a row ends only at LF, CRLF or a lone CR, so such a row reads as one event, and a row past a JSON limit refuses with `StoreError` ("Invalid JSON on line N"), is skipped by the lenient reader, and raises `ValueError` when seeding a scratch log.
