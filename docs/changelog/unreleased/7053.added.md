- **`spec-kitty charter org add` / `remove` register an org Charter Pack with a project** (#7053, #6267). **Before:** the only path was hand-writing a `charter_packs.org.packs[]` entry in `.kittify/config.yaml`, a CLI-managed file whose indentation mistakes silently disable the whole org layer. **After:** `charter org add <name> --local-path <dir>` validates the pack exactly as `charter org validate` does and writes one canonical entry, preserving comments and unrelated keys; `--url`/`--ref` registers a published pack for `charter fetch` to materialize, `--force` replaces an existing registration in place. `charter org remove <name>` deletes exactly that entry and leaves the pack directory on disk. Both are offline, refuse without writing, and accept `--json`.
