- **User-global skills that an earlier Spec Kitty release wrote are refreshed again** (#7700, #5983). **Before:** a skill file under `~/.claude/skills`, `~/.agents/skills` or another user-global root that Spec Kitty itself had written in an older release, but that its asset record did not list, was kept as "Unproven existing asset" forever, while `agent-skills.lock` still said the skills were current; a retired skill's unedited files were never removed. **After:** a file whose bytes match a render Spec Kitty shipped for that exact skill path is refreshed (or, for a retired skill, removed). Anything else stays byte-for-byte as it is, and `agent-skills.lock` is not written while a file of a skill Spec Kitty ships today is kept stale, so the next run checks again. The list of shipped renders is generated from the repository history and frozen in the package.
