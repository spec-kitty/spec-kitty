- **The doc-kitty docsite renders Mermaid and PlantUML diagrams at build time** (#6936, epic #6100). **Before:** the site build shipped every diagram as a raw code block. **After:** the shared `docs-site-build.yml` job renders them to static SVG: Mermaid through an exact-pinned Playwright Chromium, PlantUML against a digest-pinned `plantuml-server` service in the `SANDBOX` security profile. Before the build, doc-kitty's canary check proves the running service refuses a remote `!include`, and the built-site check fails on any published diagram left as a raw block, a render error or a missing figure, or a `plantuml.com` reference. ADR 2026-08-12-1 carries an amendment for the service-container guarantee; the DocFX diagram path is unchanged. Toolkit gaps are filed as spec-kitty/doc-kitty#314.
