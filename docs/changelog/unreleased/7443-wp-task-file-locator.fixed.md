- **A work package's task file is found by one rule everywhere** (#7443). **Before:** the dependency guard matched the work package id case-sensitively, so a lowercase `tasks/wp02-x.md` declared no dependencies and that work package could be claimed while its dependencies were unfinished; a directory named like a task file was read as one. **After:** the dependency guard, the subtask roster and the work package view all match the id case-insensitively (`readme.md` never matches), so the dependencies of a lowercase task file are honored; a directory or dangling link named like a task file is refused by the guard and the roster with `<name> is not a regular file`, and the view treats it as no file.
