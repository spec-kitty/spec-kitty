- **Agent orientation files name the recorded project, and `upgrade` and `doctor tool-surfaces --fix` repair a wrong one** (#5215). **Before:** the orientation block in `.claude/CLAUDE.md`, `AGENTS.md` and similar files could name the checkout directory while the SessionStart hook printed `project.slug`; a wrong block at the current version was reported `present` and never repaired, and `upgrade` wrote the directory name over older blocks. **After:** the committed block names `project.slug`, else the project's own `origin` repository name, else `unknown`, and always says `(healthy)`; only the hook shows live health. A block whose name or health differs is reported stale, and `--fix` and `upgrade` rewrite it to identical bytes. Hand-edited blocks are left alone. `derive_project_slug` now falls back to the directory name when the `origin` URL names no repository.
