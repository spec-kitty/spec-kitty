- **`ci-aggregate.yml` declares least-privilege token scopes** (#5554). **Before:** with no workflow-level `permissions:`, every job inherited the repository's default `GITHUB_TOKEN` scopes in the privileged `workflow_run` context. **After:** `contents: read` is the workflow floor and each job grants its own extra read scopes, pinned by `tests/ci/test_aggregate_permissions.py`.
- **The `docs-site` build is a required pull-request gate** (#6937). **Before:** the doc-kitty build carried job-level `continue-on-error` and sat outside `router-gate.needs:`, so a broken site merged. **After:** it is in `needs:` without `continue-on-error`, and the router tests pin both halves.
- **`scripts/docs/check_docs_freshness.py` runs as a bare file** (#5179). **Before:** `python scripts/docs/check_docs_freshness.py --ci` raised `ModuleNotFoundError: No module named 'scripts'` once a sub-check imported a sibling. **After:** the script anchors the repository root on `sys.path` itself.
- **The CLI-reference freshness check ignores Rich markup escapes** (#5184). **Before:** a help body needing a literal `[` reported `HELP-DRIFT` on every run. **After:** `\[` is unescaped on both sides before comparison, and a genuine body change is still drift.
- **Two tests no longer fail inside a lane worktree** (#5441, #5740). **Before:** the docs-retrieval-index test shelled out to `uv run`, which has no project environment in a lane worktree, and the internal-pack asset test anchored its expected directory to the worktree checkout. **After:** the first runs the renderer with `sys.executable`, the second derives its expectation from `locate_project_root()`.
- **The P1 census oracle names all four enforcement-allowlist gates** (#4361). **Before:** `test_integration_boundary` was missing from the oracle's set, so the planted-regression test could not cover it. **After:** the oracle and the test's gate tuple name the same four gates, and the fallback iterates them.
- **The charter cascade tests assert the current in-force report, and the shared `seed_graph` fixture writes a schema-valid graph** (#7112, #2778). **Before:** the tests still expected "not activated" and the fixture omitted the pydantic-required `generated_at`/`generated_by`, so any suite reaching `load_validated_graph` through it failed for an unrelated reason. **After:** both match the current behavior.
