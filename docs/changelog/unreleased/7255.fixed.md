- **`finalize-tasks` records a planning commit for a Mission whose `lanes.json` never had one** (#7210). **Before:** an in-flight Mission whose `lanes.json` predates the planning pin refused every approved work package with `EVIDENCE_WINDOW_UNCOMPUTABLE`, and the remedy it named did not work: plain `finalize-tasks` kept the pin empty with a warning, and `--refresh-planning-commit` recorded the live target tip, which leaves an empty window. **After:** with no pin recorded, plain `finalize-tasks` records the target-branch commit just before the Mission's `tasks/WP*.md` first appeared there, using the lookup `consolidate --skip-lanes` uses (#7209), and reports it as `derived`, provided every lane branch contains that commit. The refusal now names this route and warns against `--refresh-planning-commit`. **What to do:** for an older Mission that refuses, run `spec-kitty agent mission finalize-tasks` without flags, then re-run.
- **`spec-kitty doctor mission-state --fix` rebuilds `lanes.json` with a planning commit the evidence gate can use** (#7210). **Before:** rebuilding a missing `lanes.json` for a Mission whose work had already started recorded the live target-branch tip as its planning commit, so work already committed on the target branch fell outside the evidence window. **After:** the rebuild records the commit `finalize-tasks` derives, the one just before the Mission's `tasks/WP*.md` first appeared on the target branch. When none can be derived it keeps the live tip, reports `lanes_rebuilt_pin_is_target_tip`, and prints a warning. **What to do:** nothing.
