- **Decision Moment records are written byte-safe, so a Mission that opens one passes `validate-encoding`** (#6878, #6579). **Before:** `src/specify_cli/decisions/store.py` rendered the record's `## Change log` bullets with a literal U+2014 em dash (`- \`<ts>\` — opened`), so every mission that opened a decision wrote a `kitty-specs/<slug>/decisions/DM-*.md` whose bytes the strict ASCII gate refused, and a maintainer had to run `validate-encoding --fix` over a file the tool itself wrote. **After:** both bullets render through one ASCII separator (`- \`<ts>\` - opened`), so a written record is ASCII for ASCII inputs in every status and the gate passes without a repair pass. Authored prose is still rendered verbatim and still flagged by the gate; `validate-encoding` and its mapping table are unchanged, and records already on disk can be repaired with `--fix` as before.
