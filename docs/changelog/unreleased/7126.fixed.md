- **A review rewind from `in_review` to `in_progress` now records a status event hosted sync accepts** (#7080). **Before:** `agent status emit WP01 --to in_progress` (and the `orchestrator-api` transition door) recorded `review_ref: null` even when the caller supplied a structured review result, and a pointerless forced rewind exited 0 — both rows were rejected at sync and the rework never propagated. **After:** the status emit path records `review_result.reference` as the event's `review_ref` when no `--review-ref` was given (as `move-task` already did), a forced `in_review -> in_progress` with no pointer is refused before the append, and `status validate` reports a row written before this fix. **What to do:** a reviewer's rewind passes `--review-result-json` (its `reference` is recorded); an operator rewind that is not a review result passes `--review-ref <ref>`.
