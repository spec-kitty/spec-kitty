- **The companion platform wheels can no longer be tagged with an OS older than the service binary they carry** (#6948). **Before:** a wheel's tag stated a minimum nobody checked — `manylinux_2_39` from a workflow flag, `macosx_11_0_arm64` from a constant — so a binary built against a newer glibc or macOS still tagged and installed onto older hosts, passed the digest check, and died at exec. **After:** the release build reads the floor out of every binary it bundles (the highest `GLIBC_x.y` version need, or the Mach-O `minos`) and refuses with `SERVICE_PLATFORM_FLOOR_EXCEEDED`, or `SERVICE_PLATFORM_FLOOR_UNREADABLE` when it cannot read one, before writing the wheel; `--verify` re-checks the bundled bytes and `--macos-floor` is the new build input beside `--glibc-floor`. **What to do:** nothing; the published tags and the wheel contents are unchanged.
