- **`spec-kitty consolidate` lists the work packages it judged without a recorded window** (#7403). **Before:** a work package whose window was not recorded (for example in a Mission started before this release) was judged by its approval stamp without a word, and a `single_branch` Mission always opened a work package's window at its first claim. **After:** the fresh run, `--resume` and `--dry-run` list such work packages under "Window gaps (judged by the approval-stamp bound)", and `--dry-run --json` carries them as `window_gaps`. A `single_branch` work package's window opens where its status recorded it, so work abandoned before a work package was sent back to `planned` and claimed again is refused with `LANE_MOVED_AFTER_APPROVAL`.
