- **`charter generate`, `charter interview` and `charter status` report one path spelling on every OS** (#7044). **Before:** both `--json` envelopes, their `Charter:` / `Interview file:` lines, the missing and malformed interview-answers errors, and the `charter status` family's output spelled repository-relative paths with the host separator, so Windows showed `.kittify\charter\charter.md` where Linux and macOS showed `.kittify/charter/charter.md`. **After:** every repository-relative path those commands report is POSIX, rendered through one seam (`kernel.charter_pack_paths.repo_relative_posix()`); a path outside the repository keeps its native spelling.
