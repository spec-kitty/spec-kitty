- **`spec-kitty doctor skills --fix` repairs a command skill whose file and manifest agree but no longer match today's render** (#5281). **Before:** `doctor skills` compared each command skill only with the hash its manifest recorded, so a file corrupted at install time (for example by the #4998 CRLF bug), whose manifest recorded the same corrupted hash, looked healthy and `--fix` did nothing; only `doctor tool-surfaces --kind command-skill --fix` and `upgrade` repaired it. **After:** such a file is reported as `outdated` (`--json` key `outdated`), counts as an issue, and `--fix` re-installs it, the same repair the other two paths make.
