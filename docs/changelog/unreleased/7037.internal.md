- **A scope-only pull request no longer makes both heavy CI legs collect a test universe no selected gate reads** (#7037, #7001, #6994): `collect_universe_prestep consumers` now takes `--gates-file` (default `SK_BATTERY_GATES_FILE`) and answers for the gates the diff selected, so a leg whose selected gates hold no collecting test skips every universe step. A leg that collects still collects the whole tree; no file, full mode or an unreadable file behaves as documented in [CI gate mechanics](../development/reference/ci-gate-mechanics.md#what-a-scope-only-leg-skips).
