- **`migrate backfill-identity` treats git's dubious-ownership refusal as a refusal on its own** (#7061). **Before:** the refusal only held when the `.git` search above the Mission also found the repository, so a search that stopped short of the repository git refused could read the Mission as untracked and let a new `mission_id` be minted. **After:** git's ownership diagnosis alone refuses with `TRACKED_META_UNAVAILABLE`, and no identity is minted. Hardening: the nightly failure filed as #7061 was a test-isolation fault (the runner's `safe.directory = *`), not an observed mint.
