- **`spec-kitty consolidate` refuses when git cannot read a file's history on an approved lane** (#5048, #7403). **Before:** it treated the file as deleted by the lane, landed the lanes, then failed the landing as an unattributable blob and rolled it back. **After:** it refuses at claim time with "a git probe failed while building the approved-WP claim", naming the file, the commit and the git error, and exits 1 before any branch moves. A file the lane really deleted is still recorded as deleted and lands.
