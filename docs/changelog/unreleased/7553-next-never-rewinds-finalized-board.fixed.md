- **An advancing `spec-kitty next` never sends a finalized software-dev board back to `discovery`** (#7553, #5929, #7565). **Before:** with no run, an untouched run, or a run at a planning step, `next` walked the Mission's runtime from its first step, recording false step rows after the work packages were finished, accepted or still in progress; a board without `lanes.json` raised `MissingLanesError` with nothing on stdout. **After:** the board answers first and starts or advances no run. A finished board not accepted since its latest work-package transition returns `blocked` with `MISSION_AWAITING_ACCEPTANCE`, and `terminal` once accepted. A board step that cannot be dispatched returns `blocked` with `BOARD_STEP_NOT_DISPATCHABLE`. A board step that needs a missing `lanes.json` returns `blocked` with `LANES_MANIFEST_MISSING`.
- **A read-only `spec-kitty next` keeps a fresh Mission's first decision** (#7553). **Before:** a query of an untouched run whose first step needs input dropped that decision's question. **After:** the query carries its `question`, `decision_id` and options, and an envelope with a question but no decision cannot be built.
