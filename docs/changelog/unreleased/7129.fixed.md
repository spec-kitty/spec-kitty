- **`spec-kitty agent tracer-append` writes into the checkout that owns the Mission** (#7081). **Before:** it resolved the repository root, so from an owned checkout it staged `traces/<category>.md` into the primary checkout on protected `main` and refused `PROTECTED_BRANCH_REFUSED`, losing the finding and leaving untracked residue. **After:** it accepts `--owned-checkout` and adopts the checkout it is invoked from, taking the write root, write branch and mission-scoped protection policy from that owned Mission fact, and refuses a typed owned error before writing anything when the target is invalid. A non-owned invocation is unchanged.
