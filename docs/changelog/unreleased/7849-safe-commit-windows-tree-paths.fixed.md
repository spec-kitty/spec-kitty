- **Pinned-parent commits of nested paths work on Windows** (#7849). **Before:** on Windows, every `safe_commit` that pinned its parent and asserted exact bytes for a nested path (setup-plan's lifecycle commit, the planning-pin `lanes.json` commit, the decision-lock `.gitignore` commit) refused with `could not inspect staged blob ... fatal: Needed a single revision`, so `setup-plan` failed with `SETUP_PLAN_LIFECYCLE_UNCOMMITTED`. The decision runtime-lock tree check and the submodule (gitlink) probe could also miss a nested path and pass. **After:** the commit seam names every path it looks up in a git tree or index with `/`, as git does, and the kernel's exact tree-entry lookup (`tree_entry`, and `blob_at` through it) accepts a Windows `\`-separated path as the same entry (on POSIX a `\` is still a filename character).
