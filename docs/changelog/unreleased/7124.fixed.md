- **A first `spec-kitty consolidate` lands the coordination commit it never received instead of refusing a complete landing** (#6871, #6857). **Before:** the late-window projection and its proof ran only on `--resume`, so a coordination commit made between the projection gate and the teardown made a first run refuse at the gate, leaving you to hand-assemble a landing that already stood. **After:** a first run projects everything committed after the coordination tip it captured, commits it on the target, and proves every record byte-identical there before the branch goes. A record it cannot land refuses with `Error code: COORD_LATE_PROJECTION_REFUSED.`, keeps the branch, worktree and marker, and names its repair. A first run that recorded no coordination tip can still lose such a commit with the branch (#7121). **What to do:** follow the refusal's repair, then re-run.
