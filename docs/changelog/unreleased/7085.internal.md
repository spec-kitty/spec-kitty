- **The acceptance suite's "real home stayed clean" guard can be told the host is shared** (#7026): the comparison still covers the whole real `~/.spec-kitty` by default, but `SPEC_KITTY_ACCEPTANCE_SHARED_HOST=1` also skips `spec-kitty-prompts/` and `gate-locks/` — the two runtime-state subtrees a concurrent Mission writes (per-repository prompt files and machine-wide gate locks) — so another Mission's prompt file no longer reddens a scenario that passed every step. The switch is ignored on a GitHub Actions runner, and every scenario runs a control that proves a planted leak outside those subtrees still fails the guard.
