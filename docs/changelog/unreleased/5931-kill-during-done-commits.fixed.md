- **`spec-kitty consolidate --abort` undoes a run killed while it records work packages as done** (#5931, #7544). **Before:** each `status transition` commit `consolidate` made on the coordination branch while recording work packages as done left no advance intent in the consolidation record, so after a kill between two of those commits `--abort` reported the run's own commit as `moved by another actor since this run`, kept the branch on it, and every re-run refused with `UNEXPLAINED_BRANCH_MOVE`. **After:** inside the run, those commits are built on the branch tip just read, the intent is saved before a compare-and-swap moves the branch, and a branch that moved in between makes the commit fail instead of being overwritten. `--abort` restores the branch to its pre-consolidation tip. Outside `consolidate`, commits are made as before.
