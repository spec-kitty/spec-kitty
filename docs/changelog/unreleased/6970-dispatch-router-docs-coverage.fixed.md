- **`spec-kitty dispatch` routes an ordinary documentation request instead of refusing it, and a refusal now names the closest profiles and the remedy** (#6970). **Before:** `dispatch "mark ADR-0068 Accepted and regenerate the ADR index"` exited 1 with `ROUTER_NO_MATCH` and an empty candidate list — no shipped profile declared `adr`, `docs`, `changelog`, `readme` or `guide` — and a declared multi-word or hyphenated keyword such as `knowledge base` or `transcribe-notes` could never match. **After:** documentation-artifact nouns route to the documentation profile (`router_confidence: domain_keyword`), bare `index` stays out of that vocabulary, those declared keywords match as a fallback tier so no request that routed before moves, and both `ROUTER_NO_MATCH` and `ROUTER_AMBIGUOUS` report ordered candidates with a runnable `--profile <id>` command (a tie names every tied id); without `--json` the refusal prints readable lines instead of a raw JSON envelope.
