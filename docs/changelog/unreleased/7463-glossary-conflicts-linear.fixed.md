- **`spec-kitty glossary conflicts` slowed quadratically on long glossary event logs** (#7463). **Before:** each resolved-only event rebuilt the set of known conflict ids, so listing conflicts cost O(resolved x conflicts) — about 563 ms at 4000 resolved events. **After:** the set is built once and extended as ids are appended (one pass, about 3 ms at the same size); the output is unchanged.
