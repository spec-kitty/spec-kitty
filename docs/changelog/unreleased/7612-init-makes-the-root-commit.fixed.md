- **`spec-kitty init` makes the first commit of a repository that has none** (#7612). **Before:** after `git init`, `spec-kitty init` left `.kittify/`, the agent files, `.gitignore` and `.gitattributes` uncommitted and printed a note, because its #7555 commit worked only on a branch that already had a commit. **After:** init makes the root commit (`chore: initialize spec-kitty project`) holding exactly the files it wrote; files you already had, staged or not, stay out of it and stay staged. `--no-commit` still opts out. With no git identity, init refuses before writing anything (`INIT_GIT_IDENTITY_MISSING`: set `user.name` and `user.email`, or pass `--no-commit`). When git refuses the commit, for example a rejecting hook, init exits 1 with `INIT_ROOT_COMMIT_FAILED`, git's reason and the files it wrote.
