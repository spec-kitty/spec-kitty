- **Installing `spec-kitty-cli` no longer pulls in the Model Context Protocol SDK and nine packages that came only with it.** **Before:** `mcp` was a declared runtime dependency, although nothing in the CLI imports it, so every install also fetched `starlette`, `uvicorn`, `sse-starlette`, `pyjwt`, `python-dotenv`, `python-multipart`, `pydantic-settings`, `httpx-sse` and, on Windows, `pywin32`. **After:** `mcp` is no longer a dependency and those packages leave the lockfile. Nothing in the CLI changes.
