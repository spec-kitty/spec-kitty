- **The CI bots' git calls run no hooks** (#7662). **Before:** the shard-recapture and docs-index-regen bots ran `git commit`, `git push`, `git fetch` and `git checkout` with the checkout's hooks enabled, so a hook a test left behind could run with the PAT in reach. **After:** each of those calls passes `-c core.hooksPath=/dev/null` (commit and push also `--no-verify`), built by `scripts/ci/bot_pr_publish.py`, and argv tests pin the flags.
