- **`finalize-tasks` commits its own writes in the coordination worktree** (#7792). This applies to a default Mission settled to `lanes_with_coord`. **Before:** a re-finalize looked for changes in the repository root checkout. It reported `commit_created: false` and left `lanes.json`, `tasks.md` and the work package files uncommitted in the coordination worktree. **After:** each file is checked and committed in the checkout that holds it. The settlement's own `meta.json` change is committed too. If the run would report nothing committed while a file it wrote is still uncommitted, it refuses with `FINALIZE_WRITES_UNCOMMITTED` and exits 1.
