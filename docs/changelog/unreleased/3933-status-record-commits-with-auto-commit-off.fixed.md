- **Policy change: `move-task` and `mark-status` now commit their whole status record even when `auto_commit` is `false`** (#3933). `auto_commit: false` no longer keeps a status record local; only an explicit `--no-auto-commit` does. **Before:** with the project setting `auto_commit: false`, `move-task` committed the lane transition but left its `--note` annotation, the refreshed `status.json` and an approval's or rejection's review-cycle verdict uncommitted (and printed `(--no-auto-commit)` although the flag was not passed), and `mark-status` left its annotation uncommitted, so every work package needed a hand commit. **After:** the status record a command writes is committed unless `--no-auto-commit` is passed explicitly; the setting still keeps the operator's own work (lane deliverables, uncommitted code) out of every commit.
