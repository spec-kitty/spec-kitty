- **`spec-kitty next` commits the event row it writes into the coordination worktree** (#5938). **Before:** every `next --result success` appended to `kitty-specs/<mission>/mission-events.jsonl` in the coordination worktree and left it untracked, so `consolidate` refused a `next`-driven coordination Mission with `MERGE_UNSAFE_WORKTREE_DIRTY` until someone committed the file by hand. **After:** `next` commits that one file there (`chore(next): record next invocation for <mission>`); nothing else in the worktree is staged, a refused commit prints a warning instead of failing `next`, and a lane cut from the coordination branch afterwards still moves to review (the lane guard accepts the inherited log the way it accepts the inherited status files).
