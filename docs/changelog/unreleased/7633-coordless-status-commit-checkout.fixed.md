- **A status commit on a Mission without a coordination branch runs where status reads look, or refuses** (#7633). **Before:** the commit ran in whichever checkout held the write branch, so on a commit-to-target or explicit `single_branch` Mission whose branch another checkout held, or a default Mission whose topic holder had no Mission directory, the status board read a checkout the commit never touched; with a lane worktree holding the branch it failed late with a HEAD mismatch. **After:** the commit takes its checkout from the placement seam, the same checkout the status read door reads, and refuses before writing anything with `STATUS_WRITE_CHECKOUT_NOT_ON_WRITE_BRANCH` when that checkout is not on the write branch. The message names the checkout and the branch to check out there.
