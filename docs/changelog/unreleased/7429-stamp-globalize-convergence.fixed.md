- **A second `spec-kitty upgrade` no longer deletes the generated `.claude/commands` files the first one kept** (#7429). **Before:** `4.0.0rc8_stamp_globalize_commands` was never recorded as settled, so every upgrade ran it again; on the second run it read the version stamp the first run had written and removed every generated `spec-kitty.*` command file the first run had kept. **After:** its own successful run settles it, so a repeat upgrade applies nothing and changes nothing.
