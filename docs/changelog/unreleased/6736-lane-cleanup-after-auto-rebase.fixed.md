- **`spec-kitty consolidate` removes an auto-rebased lane again** (#6736, #7382). **Before:** cleanup checked each lane against its tip from before the run, so a lane the run auto-rebased was kept with `WORKTREE_TIP_MOVED`, reported as "has uncommitted changes", at exit 0. On a coordination topology a lane was also kept with `NOT_LANDED_ON_NAMED_REMOTE`: it carries an older copy of the Mission's status log, which the target appends to after the landing. **After:** cleanup follows the run's own auto-rebase merge (recorded, so `--resume` keeps it) and treats the status log and `status.json` as landed when every lane event is in the target's log. Any other move or difference still keeps the lane, and a moved tip is reported as moved. `orchestrator-api consolidate-mission` does the same.
