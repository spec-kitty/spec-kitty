- **A `single_branch` Mission keeps its committed work in review after a rebase** (#7793, #7297). **Before:** `finalize-tasks --refresh-planning-commit --allow-orphaned` re-pointed the planning commit to the branch tip, and `move-task --to for_review` then refused `SINGLE_BRANCH_IMPLEMENTATION_MISSING`. A minted `single_branch` Mission's refresh refused `PLANNING_REFRESH_FAIL_CLOSED` whenever it would move the planning commit. A second plain finalize replaced a derived pin. **After:** the re-pin follows the planning commit to its rebased copy (same patch-id), or refuses with a named code and leaves `lanes.json` unchanged. A `single_branch` Mission records its planning commit from its own Mission branch. A plain finalize keeps a derived pin. A Mission an earlier version already re-pinned to the tip is not repaired: set `planning_commit_sha` in `lanes.json` by hand.
