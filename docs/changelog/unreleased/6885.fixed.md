- **`spec-kitty upgrade --dry-run` now predicts the migrations the real run applies, instead of calling a dependent migration "not needed"** (#6552). **Before:** a migration whose `detect()` reads a file or git config an earlier migration in the same run rewrites was judged against the pre-run tree (a dry run applies nothing), so `--dry-run` reported `3.2.6_issue_matrix_driver_repoint` as `not needed (project already in target state)` while the real run applied it, and `Migrations applied:` differed by that entry. **After:** a migration that declares the predecessors its `detect()` reads (`sequenced_after`; the 3.2.6 merge-driver repoint declares the gate-artifact migration) is reported applied, with a `Predicted by an earlier migration in this run (dry run)` line naming the migration it follows, and `--dry-run --verbose`'s detection preview agrees instead of saying `skipped`. A dry-run skip with no such declaration now says `not needed on the current tree` - the only claim a preview can support - and a real run's verdicts, warnings and records are unchanged.
