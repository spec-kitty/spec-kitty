- **`spec-kitty consolidate --dry-run` no longer refuses an accepted Mission over its Mission branch's own commits** (#7854, #7855). **Before:** under the default squash strategy, the forecast judged the Mission branch by its final content and then judged the Mission branch's commits a second time, commit by commit, through every lane that had merged the Mission branch, so a merge of the target into the Mission branch or a superseded commit was reported as "content commit ... belongs to NO approved WP". **After:** the lane scan skips commits the squashed tree already judged. Lane-only commits are still scanned, content no approved work package wrote still fails, and the `--strategy merge` and `rebase` checks are unchanged.
