- **`spec-kitty consolidate` after `consolidate --abort` rebuilds the coordination worktree** (#5406, #7544). **Before:** `--abort` removed the coordination worktree, and the next `consolidate` of a `lanes_with_coord` Mission refused with "lanes.json is not on the current checkout ... Run `git checkout kitty/mission-<slug>`", which told you to check the coordination branch out in the repository root checkout. **After:** the next `consolidate` rebuilds the coordination worktree from the local coordination branch and lands the Mission. When it cannot (the branch exists only on a remote), it says to fetch or create the local branch and re-run `spec-kitty consolidate`. A `single_branch` Mission keeps the `git checkout` remedy.
