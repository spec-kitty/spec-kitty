- **Moving one agent's config root outside your home folder no longer orphans the other roots' skills** (#7722). **Before:** with `CLAUDE_CONFIG_DIR`, `OPENCODE_CONFIG_DIR` or `XDG_CONFIG_HOME` pointing outside `$HOME`, the record of what Spec Kitty wrote under `~/.agents/skills` and the other user-global roots stopped resolving, so those files were kept as "Unproven existing asset" and never refreshed. **After:** the record (`~/.kittify/cache/<owner>-assets.json`) names files relative to your home folder (or by absolute path outside it), an older record keeps proving the files it named and is rewritten once, and moving a root changes nothing for the others.
