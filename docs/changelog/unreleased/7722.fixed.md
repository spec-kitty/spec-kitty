- **Moving one agent's config root outside your home folder no longer orphans the other roots' skills** (#7722). **Before:** with `CLAUDE_CONFIG_DIR`, `OPENCODE_CONFIG_DIR` or `XDG_CONFIG_HOME` pointing outside `$HOME`, the record of what Spec Kitty wrote under `~/.agents/skills` and the other user-global roots stopped resolving, so those files were kept as "Unproven existing asset" and never refreshed. **After:** `~/.kittify/cache/<owner>-assets.json` is always keyed from the folder that holds your home folder, records outside it go to `<owner>-external-assets.json`, and an older record keeps proving the files it named. Older Spec Kitty releases on the same machine still read the record.
