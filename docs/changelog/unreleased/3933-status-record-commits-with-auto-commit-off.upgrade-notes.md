- **`auto_commit: false` no longer keeps a work package's status record local** (#3933). `move-task` and `mark-status` now commit the whole record they write (transition, `--note`, `status.json`, review-cycle verdict) unless you pass `--no-auto-commit` explicitly. The setting still keeps your own work (lane deliverables, uncommitted code) out of every commit. If you relied on the project setting alone to keep status records uncommitted, pass `--no-auto-commit` on those commands.
