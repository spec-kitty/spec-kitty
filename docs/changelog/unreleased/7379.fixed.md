- **Refused `charter synthesize` runs no longer accumulate failed staging directories without bound** (#6723). **Before:** every refusal preserved `.kittify/charter/.staging/<run_id>.failed/` for diagnosis and nothing pruned them, so a repeatedly-refused project — exactly what an agent retrying the implement gate's remedy produces — grew one directory per attempt (#4226 counted 15, then 16). **After:** the newest 3 are kept and older ones are removed as the next refusal is preserved; the failure the command just reported is never removed, a live `.staging/<run_id>/` is never touched, and the refusal hint says how many are kept. Nothing to do: a tree that already holds more than 3 is brought down to 3 by the next refusal.
