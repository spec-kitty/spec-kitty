- **Your next `spec-kitty upgrade` may rewrite the orientation block once** (#5215). Blocks that name the checkout directory, carry an `Upgrade available` line or `(upgrade-available)` health, or still use the pre-ASCII glyphs are refreshed to the current rendering and committed with the other upgrade changes. Later upgrades change only its version stamp. A project with no `project.slug` now shows the repository name of its own `origin` remote, or `project: unknown` when it has none or is not itself a git repository (for example a project inside a dotfiles repository or a monorepo), instead of the directory name.
