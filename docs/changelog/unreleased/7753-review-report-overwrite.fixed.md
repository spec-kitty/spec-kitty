- **`spec-kitty review` no longer overwrites a mission review it did not write** (#7753). **Before:** it replaced `kitty-specs/<slug>/mission-review-report.md` unconditionally, so an agent-written mission review saved under that name was lost, with no backup. **After:** it still refreshes its own previous machine report, but when any other file is at that path it refuses with `MISSION_REVIEW_REPORT_PATH_OCCUPIED` before running any gate, writes nothing and names the move to `kitty-specs/<slug>/mission-review.md`. The `spec-kitty-mission-review` skill now saves its report at `kitty-specs/<slug>/mission-review.md`.
