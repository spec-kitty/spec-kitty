- **`spec-kitty consolidate --abort` cleans up its own status files in the coordination worktree of a settled default Mission** (#7540, #7544). **Before:** after a `consolidate` that was killed or failed, the rollback could not read the Mission's topology, because a Mission settled to `lanes_with_coord` keeps its `meta.json` only in the coordination worktree. It then treated every change as an operator edit and left the run's own uncommitted `status.events.jsonl` and `status.json` there "as found", with a request to commit or stash them. **After:** the residue check reads the topology from where the Mission's metadata lives (the placement seam's `PRIMARY_METADATA` directory, then the repository root checkout), so the rollback resets those status files to the branch tip. An operator's own edit in that worktree is still kept, and the rollback still refuses to reset over it.
