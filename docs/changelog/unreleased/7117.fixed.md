- **Legacy Missions below harmless `.git` residue can acquire an identity without re-identifying damaged repositories** (#7084, #7117). **Before:** a stray empty or hook/lock-only `.git` directory made `upgrade` and `migrate backfill-identity` refuse with `TRACKED_META_UNAVAILABLE`, although no tracked identity existed there. **After:** only those known non-storage directories are ruled out. A missing or dangling `HEAD` does not make a repository's objects, refs or index disposable; other contents, pointers, unreadable entries and explicit Git repository/storage redirects remain fail-closed. No second identity is minted over a recoverable one. **What to do:** re-run a backfill refused solely because of harmless residue; repair an actual damaged repository before retrying it.
