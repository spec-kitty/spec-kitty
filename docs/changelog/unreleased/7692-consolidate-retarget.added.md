- **`spec-kitty consolidate --target <branch> --retarget` makes the branch the Mission's recorded target** (#7692). Every write of the run then lands there. The run first commits `target_branch` and a `retarget_history` entry to the Mission's `meta.json`, with an optional `--retarget-reason`. A failed run restores the branches, and `--resume` applies the retarget again. `--dry-run --json` reports it as `"retarget": {"from": ..., "to": ...}`. New refusal codes, all reported before any branch moves: `RETARGET_RECORD_UNWRITABLE`, `RETARGET_WRITE_BRANCH_IS_RECORDED_TARGET` and `RETARGET_RESUME_MISMATCH`. A protected new target is refused with `PROTECTED_BRANCH_REFUSED`. It works on `lanes` and `lanes_with_coord` Missions, and on Missions created without `--topology`. `orchestrator-api consolidate-mission` cannot retarget.
