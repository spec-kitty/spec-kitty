- **A `subtasks:` entry that is not a task id is refused with the fix** (#7442). **Before:** an entry such as `- id: T001` (a map), a list, a number with a decimal point, a date, `true` or `null` was turned into its text, an id nobody could mark, so `move-task --to for_review` stayed blocked for good; an integer too long to print escaped as a raw `ValueError`. **After:** only text and whole-number entries are task ids. Any other entry refuses with the work package file, the entry's position and type, and the expected form (`- T001`): the `for_review` checks refuse, `mark-status` refuses for the whole Mission until the file is fixed (a roster it cannot read could hide a second owner of the subtask), and the work package view shows no authored subtasks for that work package.
