- **A Mission's default topology is settled by size at the first `finalize-tasks`** (#7282). **Before:** `agent mission create` without `--topology` chose `coord` or `lanes` from the current branch. **After:** create mints one Mission topic branch and no worktree on every target; the first `finalize-tasks` keeps `single_branch` for at most two work packages or at most one code lane, and otherwise settles `lanes_with_coord` with the topic branch as the coordination branch (ADR `2026-11-06-3`). `--validate-only` only previews, and a failed settlement is undone and refuses with `TOPOLOGY_SETTLEMENT_REFUSED`. `consolidate` refuses the coordination teardown, keeping the branch, while the topic branch holds planning changes the target does not carry. **What to do:** pass `--topology` to choose a topology yourself; `lanes` and `coord` are explicit-only.
