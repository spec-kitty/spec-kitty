- **Mission dossier commit SHAs are branch-relative provenance and are never repointed after a rebase merge** (#7322). ADR 2026-11-07-1 defines `merged_commit`, `accept_commit`, `lane_head` and the other dossier SHAs as naming commits on the branch the Mission was built on, so landing passes stop rewriting them and the archive freeze stays byte-strict with no stale-SHA exceptions. The new gate `tests/architectural/test_dossier_sha_provenance.py` fails when a tool-written dossier file records a commit SHA under a field nobody has classified.
