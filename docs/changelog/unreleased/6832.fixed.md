- **A review rejection no longer leaves its feedback draft behind to block the next `move-task --to for_review`** (#6832, #6632). **Before:** the prompt called `kitty-specs/<mission>/tasks/<wp>/review-feedback-N.md` "committed with the project", but the rejection committed only the derived `review-cycle-N.md`, so that file stayed untracked and the WP's next `move-task --to for_review` refused on it (`Blocking: 1 uncommitted file(s)`). **After:** the record holds the reviewer's text, so the rejection removes that work package's own `review-feedback-*.md` once the committed record is verified to contain it, says so on stderr, and reports `retired_feedback_draft` in `--json`. Any other file (`notes.md`, another work package's draft, a symlink, a tracked or edited draft) is kept, with a stderr warning when it was a draft that could not be removed safely. There is no opt-out.
