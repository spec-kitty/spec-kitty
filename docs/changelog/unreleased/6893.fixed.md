- **The TeamSpace dry-run's `WPStatusChanged` payload is built by the contract model, so it carries `mission_id` and can no longer drift from the wire shape** (#6449). **Before:** `doctor mission-state --teamspace-dry-run` hand-assembled each synthesized payload, so a row's `mission_id` was silently dropped and a shape drift only surfaced in the later conformance pass. **After:** the payload is constructed through `spec_kitty_events.status.StatusTransitionPayload`, so the same row now emits its `mission_id`, and a row the model cannot represent is still reported as `PAYLOAD_INVALID` (with `model_violations`) instead of aborting the run. `reason`, `review_ref` and `evidence` keep their explicit `null`s; evidence is emitted as the contract renders it, so an empty `verification` list appears where the local row omitted it. `envelope_sha256` changes for rows whose payload gained `mission_id`.
