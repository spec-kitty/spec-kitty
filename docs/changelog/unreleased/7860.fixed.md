- **A default Mission's planning work package is worked and evidenced on its Mission branch until the Mission lands** (#7860). **Before:** for a Mission created without `--topology` that settled `lanes_with_coord`, `implement` sent a planning work package to the repository root checkout on the target, the evidence check ended its window at the target, and work committed on the Mission branch was refused with `IMPLEMENTATION_MISSING`. **After:** `implement` names the coordination worktree, the evidence window runs from the commit that introduced the claim to the Mission branch (content written before the claim never counts), `move-task`, `accept`, `consolidate` and the orchestrator API judge that one window, and `consolidate` lands the work. A Mission branch no checkout holds refuses with `PLANNING_CHECKOUT_MISSING`. Other Missions and code lanes are unchanged.
