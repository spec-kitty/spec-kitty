- **A default Mission's planning work package is worked and evidenced on its Mission branch until the Mission lands** (#7860). **Before:** for a Mission created without `--topology` that settled `lanes_with_coord`, `implement` sent a planning work package to the repository root checkout on the target, and work committed on the Mission branch was refused with `IMPLEMENTATION_MISSING`. **After:** `implement` names the coordination worktree, the evidence window runs from the commit that introduced the claim to the Mission branch, `move-task`, `accept`, `consolidate` and the orchestrator API judge that one window, and `consolidate` lands the work. The landing check credits each approved planning work package only for its own `owned_files`, only for commits made after its claim, and a file only when every change to it since the recorded Mission base is credited; otherwise the lane authors nothing, and the refusal names the lane, the reason and the remedy. A Mission branch no checkout holds refuses with `PLANNING_CHECKOUT_MISSING`. Rules and remedies: `docs/migrations/planning-lane-write-branch.md`.
