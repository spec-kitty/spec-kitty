- The glossary pipeline performance tests and the test that holds `doctor ops --close-stale` under 5 s on 10,000 Op files now take the median of five in-process samples (the glossary ones after an untimed warm-up) instead of one call, through the new `median_in_process_seconds` helper in `tests/_perf_helpers.py`. Each glossary test failed when run alone, because it timed the process's first `jsonschema` import (about 1 s in the dev environment); a one-off runner stall turned the nightly `performance` suite red with no code change. Budgets are unchanged (#7704).
- The `performance` job of `ci-nightly.yml` now runs weekly, on the Sunday run, instead of every night; a manual `workflow_dispatch` still runs it on demand, and a red weekly run still opens the deduped `performance` P0 issue (#7704).
- The release gate (`scripts/ci/release_nightly_gate.py`) now also requires a green `ci-nightly` run from the last 7 days in which the `performance` job executed, on the release commit or a `main` ancestor of it; a run that skipped the job does not count, and the newest run that executed it is the verdict, so a newer red outvotes an older green. Without one, `--dispatch` runs the nightly by the release tag, and without `--dispatch` the gate refuses and names that remedy (#7704).
- `cyclonedx-bom` (release SBOM generation) moves from the `lint` extra to a non-default `sbom` dependency group that only the release workflow installs (`uv sync --group sbom`). It pulled in `rfc3987-syntax`, whose import added about 1 s to the first glossary event of every dev and CI process. A guard test keeps it out of every extra and default group. `pip install spec-kitty-cli[lint]` therefore no longer installs `cyclonedx-bom`, since dependency groups are not published metadata. The nightly `pip-audit` gate now exports `--all-groups`, so the release-only group is still audited (#7704).
- Fork guards in `ci-nightly.yml` and seven other workflows no longer name events those workflows are never triggered by (a `pull_request` or `workflow_dispatch` atom with no matching trigger); a guard test pins that (#7704).
