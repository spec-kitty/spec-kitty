- **The bulk-edit review gate judges the work package's own review range** (#7726). **Before:** on `single_branch` the gate diffed the Mission branch against itself and passed having checked nothing, or refused on `rev-parse` when that branch was absent locally. **After:** it diffs the work package's review range (window open to its `for_review` submission, recorded as commits) on every topology, so a forbidden edit is refused and no local Mission branch is needed. An undeterminable range refuses with `BULK_EDIT_REVIEW_RANGE_UNAVAILABLE`, one with no commit outside bookkeeping with `BULK_EDIT_REVIEW_RANGE_EMPTY`. **Note:** this tightens a gate: a `single_branch` bulk-edit review that passed before can now refuse.
