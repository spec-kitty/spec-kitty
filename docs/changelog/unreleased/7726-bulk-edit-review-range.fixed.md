- **The bulk-edit review gate judges the work package's own review range** (#7726). **Before:** on `single_branch` the gate diffed the Mission branch against itself and passed having checked nothing. **After:** it diffs from the work package's recorded window open, leaving Mission bookkeeping out, so a forbidden edit is refused. On a commit-to-target target and a planning branch, content a merge brought in is not judged. A window it cannot judge refuses with `BULK_EDIT_REVIEW_RANGE_UNAVAILABLE`, `BULK_EDIT_REVIEW_RANGE_EMPTY` or `BULK_EDIT_REVIEW_TIP_REWRITTEN`. A missing local Mission branch now names the command that restores it. **Note:** this tightens a gate.
