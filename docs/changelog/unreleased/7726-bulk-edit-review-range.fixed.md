- **The bulk-edit review gate judges the work package's own review range** (#7726). **Before:** on `single_branch` the gate diffed the Mission branch against itself and passed having checked nothing, or refused on `rev-parse` when that branch was absent locally. **After:** it diffs from the work package's recorded window open (to its submission on `single_branch`, to the live lane head on lanes), leaving Mission bookkeeping out, so a forbidden edit is refused and no local Mission branch is needed. A range it cannot judge refuses with `BULK_EDIT_REVIEW_RANGE_UNAVAILABLE`, `BULK_EDIT_REVIEW_RANGE_EMPTY` or `BULK_EDIT_REVIEW_TIP_REWRITTEN`. **Note:** this tightens a gate: a `single_branch` bulk-edit review that passed before can now refuse.
