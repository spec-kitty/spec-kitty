- **SonarCloud no longer reports most of `main` as untested** (#7531). **Before:** the scan of `main` took its coverage from the diff-selected `CI Modules` push run, which tests only the modules a commit touched (0 to 20 of 40 shards), so SonarCloud counted every other source file as 0% covered, and an incomplete or empty set of reports was published without a warning. **After:** the scan runs when the `CI Nightly` run on `main` completes and takes coverage from that run's full module matrix at the same commit. Unless every shard in `.github/ci-module-registry.yml` has a coverage report, the scan runs without coverage and a warning names the missing shards, so a partial figure is never published.
