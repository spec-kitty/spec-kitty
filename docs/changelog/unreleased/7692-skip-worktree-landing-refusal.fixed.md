- **`spec-kitty consolidate` refuses a skip-worktree entry it would write** (#7692). **Before:** with the skip-worktree bit on a Mission file, such as `meta.json`, in the target's checkout, the run landed, its own `meta.json` write was left out of its bookkeeping commit, the post-merge check failed, and the rollback restored the branches but left the landing staged and kept the merge record. **After:** the run is refused before any branch moves, with `CHECKOUT_SKIP_WORKTREE_ENTRIES`; clear the bit with `git update-index --no-skip-worktree <path>`. `--dry-run` and `orchestrator-api consolidate-mission` (contract 1.29.0) report the same code. Sparse-checkout exclusions are not affected.
