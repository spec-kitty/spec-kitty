- **`spec-kitty consolidate` refuses a skip-worktree entry the landing would overwrite** (#7692). **Before:** with the skip-worktree bit on a file the landing writes, such as the Mission's `meta.json`, in the target branch's checkout, the run landed, failed to resync that checkout and exited 1. The rollback restored the branches but left the landing staged in the checkout and kept the merge record. **After:** the run is refused before any branch moves, with `CHECKOUT_SKIP_WORKTREE_ENTRIES`; clear the bit with `git update-index --no-skip-worktree <path>`. `--dry-run` reports the same code. Sparse-checkout exclusions are not affected.
