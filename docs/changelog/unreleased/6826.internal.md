- **Lock-path computation now has one kernel owner, and every existing lock path is byte-identical** (#6826, #6727): `kernel.locks.anchored_lock_path` replaces three hand-written copies of the "resolve the anchor, normalise case, digest, place under the git common dir" rule (the event-log lock, the charter-synthesis lock and the Mission checkout-claim lock). Each lock keeps its digest, length, subdirectory and file name, so a process on an older spec-kitty and one on this version still name the same lock file and still exclude each other.
