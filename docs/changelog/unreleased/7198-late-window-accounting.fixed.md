- **`spec-kitty consolidate` no longer approves a late-window change it never landed** (#7198, #6871). **Before:** the proof covered only coordination records, so a status event committed on the coordination branch from another checkout — the union stage folds the coordination worktree's working tree, not the branch's commits — or a late `meta.json` edit was approved and deleted at exit 0. **After:** every change in the window is landed, proved or refused: status events by event id in the target's committed log, `status.json` only while it is that log's derived snapshot, a target-authored document when the window's change is already on the target's copy, anything else refused with `Error code: COORD_LATE_PROJECTION_REFUSED.` while branch, worktree and marker stay. **What to do:** follow the refusal's own repair, then re-run.
