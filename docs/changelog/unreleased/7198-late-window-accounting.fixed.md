- **`spec-kitty consolidate` no longer approves a late-window change it never landed** (#7198, #6871). **Before:** the proof covered only coordination records, so a status event committed on the coordination branch from another checkout — the union stage folds the coordination worktree's working tree, not the branch's commits — or a late `meta.json` edit was approved, and the branch was deleted at exit 0 with the change. **After:** every change in the window is landed, proved or refused: status events by event containment in the target's committed log, `status.json` excluded as a derived snapshot, a target-authored document accepted when the target's copy carries it, anything else refused with `Error code: COORD_LATE_PROJECTION_REFUSED.` while branch, worktree and marker stay. **What to do:** follow the refusal's own repair, then re-run.
