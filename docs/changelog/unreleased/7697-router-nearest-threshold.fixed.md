- **`spec-kitty dispatch` no longer suggests an unrelated profile on a one-word overlap** (#7697). **Before:** a `ROUTER_NO_MATCH` refusal named any profile that shared a single word with the request, so a CI request about "GitHub Actions minutes" was told to retry with `--profile minutes-mahad`. **After:** a profile is named as the closest match only when at least two of its declared domain keywords share a word with the request (canonical verbs do not count). Otherwise the refusal says there is no close match and points to `spec-kitty profiles list`.
