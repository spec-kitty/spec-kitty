- **`spec-kitty dispatch` no longer suggests an unrelated profile on a one-word overlap** (#7697). **Before:** a `ROUTER_NO_MATCH` refusal named any profile that shared a single word with the request, so a CI request about "GitHub Actions minutes" was told to retry with `--profile minutes-mahad`. **After:** a profile is named as the closest match only when at least two of its declared domain keywords, on at least two different words, overlap the request (canonical verbs do not count). Otherwise the refusal says there is no close match and points to `spec-kitty profiles list`.
- **`spec-kitty dispatch` lets domain keywords decide a verb tie or a generic route** (#7697). **Before:** "fix the github actions ci matrix" was refused as `ROUTER_AMBIGUOUS` (five language implementers tied on `fix`), and "update the github actions workflow matrix" went to `generic-agent`. **After:** when the canonical-verb candidates tie, or a route lands on a general-purpose profile (one declaring the `general-task-execution` capability, such as `generic-agent`), the one profile of the same role with the most declared domain keywords in the request takes it. A tied or empty count keeps today's result, and a route never changes role. Documentation aliases and folded verbs do not count.
