- **A commit-to-target `single_branch` Mission records its work-package window points** (#7578). **Before:** a Mission created with `--commit-to-target` recorded no `lane_head` and no `wp_window` on its status events. **After:** it records both at the head of its target branch, so a work package's review range comes from a recorded window on every topology; a missing target branch or a git failure is recorded as a gap and never refuses a move. Consolidation ignores these stamps, so its verdicts on such a Mission do not change (ADR `2026-11-08-2`, Amendment 2026-11-12). The planning lane of a `lanes` or `lanes_with_coord` Mission still records no window.
- **An owned-checkout review refuses with `OWNED_REVIEW_BASE_UNAVAILABLE` only when the work package's scoped review range cannot be determined** (#7578). **Before:** it refused when no single claim commit was found on `HEAD`. **After:** it refuses when the work package declares no `owned_files` or its review range is unavailable, and the reason names in plain words why, for example "the work package has no for_review submission (no_submission)". The code and exit code are unchanged.
