- **Plugin bundles now stage when a project configures more than one harness** (#6273). **Before:** with Claude and Codex configured, `doctor tool-surfaces --fix` mapped `.codex/agents/<id>.toml` onto the Claude bundle's `agents/<id>.md`; the shared-member guard refused the batch, `dist/spec-kitty-plugins/` was never created, the audit stayed at `missing: 3`, and the command exited 0 silently. Copilot profiles also staged as `<id>.agent.agent.md`. **After:** each bundle takes one target-native rendering per member (Claude profiles/skills in its bundle, Copilot/VS Code in theirs, the shared `.agents` rendering for command/charter skills), a Codex TOML never becomes a Markdown member, and Copilot keeps its suffix. A `--fix` that cannot repair a surface prints `Failed to repair:` with each surface and its reason and exits 1; the audit's OPTIONAL missing-manifest policy is unchanged.
