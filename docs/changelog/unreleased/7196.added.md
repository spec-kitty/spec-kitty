- **`spec-kitty doctor workspaces --prune` removes worktrees whose work has landed** (#7173). **Before:** landing worktrees and branches stayed after the merge. **After:** it gives every registered worktree a verdict: landed, not landed, unproven, or Mission-owned. `--prune` removes only worktrees whose commits are on local `origin/<primary>` (squash and rebase merges need git 2.38+), then their branches. Linux only: on macOS and Windows it removes nothing. It never fetches or uses `--force`; it prints a recreate command. It keeps dirty, locked, busy, mid-rebase and Mission worktrees. `--fix` is unchanged. **What to do:** after a merge, run `git fetch origin`, then `spec-kitty doctor workspaces --prune`. Ignored files such as `.venv/` are listed, then deleted; see the [landing runbook](../development/how-to/pr-landing.md#12-after-the-merge-remove-the-landing-worktree) for other gaps.
