- **`spec-kitty doctor ops --close-stale` closes stale work-package lifecycle records** (#7346). **Before:** a lifecycle record under `kitty-ops/lifecycle/` closed only when `spec-kitty next` reported a result, which also advances the Mission, so a record an agent left open mid-action shipped open. **After:** the sweep writes an `abandoned` record for every unpaired `started` record older than `--threshold`, in every checkout, commits the closures like the Op sweep (skipped where the repository keeps no lifecycle records, refused and reported on a protected branch) and never touches Mission files. `consolidate` counts a closure committed on an approved lane as bookkeeping. `--json` lists them under a new `lifecycle_records` key, and a fresh one left open makes the command exit 1. A CLI older than this release skips `abandoned` records and still reports the orphan.
