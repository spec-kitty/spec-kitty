- **`spec-kitty doctor state-roots` names tracked files under an ignored root** (#7597). **Before:** a root covered by an ignore rule that still held tracked files was reported as "present but not gitignored", because `git check-ignore` answers no for a tracked path. **After:** the finding says how many files git tracks under the ignored root, lists them in `--json` as `tracked_paths`, and names the remedy, `git rm -r --cached -- <root>`. Core no longer tracks the 19 pre-#4928 mission-state repair files under `.kittify/migrations/`, so `doctor` passes `state-roots` on a fresh checkout.
