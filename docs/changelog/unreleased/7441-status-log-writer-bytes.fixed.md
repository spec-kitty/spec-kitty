- **The status event log is written with contract bytes on every OS** (#7441). **Before:** a row holding NaN or Infinity was written as invalid JSON, and on Windows the log was written with CRLF line endings. **After:** a row with a non-finite number refuses with `StoreError` naming the event and nothing is written, and the log is always written with LF, so the first write on Windows rewrites an existing CRLF log to LF once. A historical row that already holds NaN or Infinity still reads, but `spec-kitty doctor mission-state --fix` now refuses to serialize it again.
