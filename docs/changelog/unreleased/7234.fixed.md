- **`spec-kitty upgrade` stops re-adding the retired `issue-matrix.md` merge-driver row** (#7217, #7174). **Before:** the first upgrade on a fresh clone appended `kitty-specs/**/issue-matrix.md merge=spec-kitty-issue-matrix` to `.gitattributes` and left it dirty, and `init` seeded the same inert row into new projects: the historical `3.2.6_gate_artifact_merge_drivers` migration is clone-local, so it was re-selected on every clone, and nothing writes `issue-matrix.md` any more (the canonical artifact is `issue-matrix.json`, whose driver merges JSON rows). **After:** that migration is superseded; `4.0.0rc8_retire_issue_matrix_md_row` keeps the `acceptance-matrix.json` and `issue-matrix.json` drivers, removes the retired row where it was already written, and leaves a correct `.gitattributes` byte-identical.
