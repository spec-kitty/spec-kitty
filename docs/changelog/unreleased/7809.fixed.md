- **`finalize-tasks` gives a docs work package its own lane in a lane Mission** (#7809). **Before:** a `planning_artifact` work package that owned `docs/` paths was placed on `lane-planning`, whose branch is the target branch, so the gates looked for its work on the target; it did not count toward the size-based topology settlement; and a work package mixing `kitty-specs/` and `docs/` paths was accepted. **After:** in a lane topology such a work package is recorded as `execution_mode: code_change` with a `Notice:` line (JSON `kind_normalised`), gets its own lane and counts as a code lane in the settlement; a work package that mixes `kitty-specs/` with other paths is refused `INVALID_WP_OWNED_FILES_KITTY_SPECS` with a split remedy. `single_branch` Missions and started work packages are unchanged.
