- **`charter activate <kind> <id> --cascade` resolves every cascaded artifact's file name once, not once per artifact** (#6777). **Before:** the cascade mapped each artifact it reached from one DRG URN to its config file name with its own fresh identity pass, re-walking and re-parsing the whole doctrine catalog for every artifact: a full `--cascade all` walk from one directive (114 artifacts across six kinds) parsed 5,028 artifact files and took 70–95 s on a development host, and the charter activation test that drives it crossed the 240 s per-test timeout on a slower CI runner. **After:** the whole target batch shares one read-only identity pass, resolved before the first activation write — 240 parses for the same walk, ~0.62–0.70× the wall clock, the same activation lists in the same order, and no change to what the command prints.
