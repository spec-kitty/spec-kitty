- **`charter synthesize --json` reports repository-relative paths with `/` on every platform** (#6277). **Before:** the fresh-seed envelope (`files_written`, `files_planned`, `planned_deletes`, `written_artifacts[].path`) and the entries recorded in `synthesis-manifest.yaml` were rendered with `str(Path.relative_to(...))`, so Windows spelled them `.kittify\charter-packs\PROVENANCE.md` where Linux and macOS spelled them `.kittify/charter-packs/PROVENANCE.md`: a consumer read a different path spelling per operating system, and the committed manifest differed by platform. **After:** every reported and recorded repository-relative path is POSIX, and the real-run envelope also normalizes a manifest written by an older Windows run. **What to do:** nothing — the envelope shape and field names are unchanged.
