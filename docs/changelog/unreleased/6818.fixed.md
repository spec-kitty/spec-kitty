- **The chain single-authority gate now counts subscript assignment as root collection and stops flagging name-keyed dict comprehensions** (#6732). **Before:** `roots[i] = pack.effective_root(r)` inside an `enumerate(registry.packs)` loop assembled a roots-only chain the gate never saw, while `{p.name: p.effective_root(r) for p in registry.packs}` — a name-paired reader the gate's own rule allows — was flagged, so #6418 had to reshape legitimate code. **After:** an assignment into a subscript is a collector, judged name-paired by its subscript key, so `roots[i] = ...` reds and `roots[p.name] = ...` does not; a `DictComp` keyed by `pack.name` is exempt, and one keyed by the bare root still reds. Iteration through `enumerate(...)`/`sorted(...)` is seen through. Each idiom is pinned by a planted violation and a planted non-violation.
