- **A retired managed skill that you never edited is removed by `doctor tool-surfaces --fix`** (#2460). **Before:** a project copy of a skill Spec Kitty retired, still equal to the hash it was installed with, was reported as present and never drained, so it stayed installed with no warning. **After:** `doctor tool-surfaces` reports it as a stale retired skill, `--fix` removes it and drops its manifest entry, and the skill verifier lists it under `retired` so the migration and repair paths see it too. An edited copy is still kept until you consent.
