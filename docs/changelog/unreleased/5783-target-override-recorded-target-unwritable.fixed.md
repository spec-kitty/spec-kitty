- **`spec-kitty consolidate --target <branch>` is refused up front when the recorded target cannot be written** (#5783, #7651). **Before:** on a Mission recorded for `main`, `--target develop` landed on `develop`, then committed the `done` transitions and the coordination flatten to `main` from a checkout on `develop`. A Mission without a coordination branch rolled back and exited 1; a coordination Mission exited 0 and left `meta.json` uncommitted. **After:** the run is refused before any branch moves, with `TARGET_OVERRIDE_RECORDED_TARGET_UNWRITABLE`: drop `--target`, or correct `target_branch` in `meta.json`. `--dry-run` reports the same code, and `orchestrator-api consolidate-mission` puts it in `data.preflight_error_code` (contract 1.28.0). `--target` never changes the record.
