- **The review prompt shows the work package's own review range and the text of the requirements it cites** (#7578). **Before:** the reviewer rebuilt the range by hand from a guessed base: an empty `<base>..HEAD` on `single_branch`, no upper end on a lane. **After:** `spec-kitty agent action review` and the `spec-kitty next` review step print one block: the range from the window open to the newest `for_review` submission, marked `[recorded]` or `[derived]` with where each end came from (for planning-lane work, status events on the work's own branch), the implementation commits, a per-file summary scoped to `owned_files` flagging changed paths outside them, the exact `git log` and `git diff` commands, and the declared text of every cited requirement. No patch text is printed and no diff file is written. When no range can be determined, the block says why and the review goes on.
