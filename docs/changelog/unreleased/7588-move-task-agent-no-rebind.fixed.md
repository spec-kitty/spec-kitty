- **`move-task --agent` on a rejection or reopen no longer makes the reviewer the work package's owner** (#7588). **Before:** `move-task WP01 --to planned --agent <reviewer>` recorded the reviewer as the owner whenever the reviewer differed from the current owner, so the released work package stayed bound to the reviewer and another implementer's claim was refused with "Agent mismatch … Use --force". `in_review → in_progress` and `approved → in_progress` did the same. **After:** on these moves `--agent` records only who acted; a move into `planned` releases the claim, so any implementer can claim the work package without `--force`. To hand the work package to a named agent, pass `--assignee <agent>` on the same move. Other moves still record `--agent` as the owner.
