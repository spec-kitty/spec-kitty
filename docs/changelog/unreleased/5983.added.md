- **`spec-kitty doctor tool-surfaces` lists the user-global skill files the skill sync kept** (#5983, #2527). `global-skill-kept-stale` names a file of a skill Spec Kitty ships whose bytes it cannot prove it wrote; `retired-skill-kept-edited` names an edited copy of a retired skill. Each is a warning with the path and what to do, and the report writes nothing. Under `--fix`, the JSON `repair.skipped_reasons` says why each skipped surface was left alone (for example, a project skill file you edited stays `drifted`), so a skip no longer reads as a completed repair.
