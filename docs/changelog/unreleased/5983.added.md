`spec-kitty doctor tool-surfaces` now lists every user-global skill file the skill sync kept: `global-skill-kept-stale` for a file of a skill Spec Kitty ships whose bytes it cannot prove it wrote, and `retired-skill-kept-edited` for an edited copy of a retired skill. Each is a warning with the file path and what to do; the report writes nothing. Under `--fix`, the JSON `repair.skipped_reasons` names why each skipped surface was left alone (for example a project skill file you edited stays `drifted`), so a skip no longer reads as a completed repair (#5983, #2527).
