- **A default Mission's planning work package records its claim base where it is worked** (#7860). **Before:** `agent action implement` recorded no claim base for a planning work package of a `lanes_with_coord` Mission, and native `implement` and `orchestrator-api start-implementation` recorded the repository root checkout's `HEAD`, so the move into review refused real work ("no recorded claim base") or diffed the whole Mission history and let a hollow work package through. **After:** every claim path records the `HEAD` of the checkout the work package is worked in (the coordination worktree before the Mission lands), the move-into-review gate diffs there and names that checkout and the Mission branch, and code dependency lanes are never merged into the Mission branch.
