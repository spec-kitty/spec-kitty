- **A project can amend its own project directive again** (#6768; #6510, #4226). **Before:** `charter resynthesize --topic directive:<PROJECT_xxx>` refused an activated project directive the project had authored and registered itself, with `Additive-only violation (FR-020 / EC-6) … colliding_urn='directive:PROJECT_xxx'`, exit 1: the snapshot the CLI handed the additive-only check listed every activated directive — the project's own included — as a built-in node. **After:** that check reads the shipped built-in layer, and the project's directives stay in the reference universe the run resolves references against, so resynthesis regenerates the directive in place while a genuine built-in URN is still refused. **What to do:** nothing; neither the session-local patch nor a `PROJECT_` id-prefix workaround is needed.
