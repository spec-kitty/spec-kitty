- **`charter resynthesize` on a directive the project wrote by hand no longer refuses, and synthesis no longer overwrites one** (#6768; #6510, #4226). **Before:** `charter resynthesize --topic directive:<PROJECT_xxx>` refused an activated directive the project authored itself, with `Additive-only violation (FR-020 / EC-6) … colliding_urn='directive:PROJECT_xxx'`, exit 1, although synthesis writes nothing for it. With no `activated_directives` key, `charter synthesize` could instead replace a hand-written directive that shared a target's id, with exit 0. **After:** resynthesis reports `Nothing to regenerate` and exits 0, leaving the file alone; edit that file directly to amend it. It also reports only the targets it generated, not every target of the topic. A target with the id of a directive synthesis did not create, of an activated org directive or of shipped doctrine refuses, whether or not it is activated. **What to do:** give a project agent profile that reuses a shipped `profile-id` its own id, and a hand-written directive that shares a synthesis target's id its own id, because both now refuse.
