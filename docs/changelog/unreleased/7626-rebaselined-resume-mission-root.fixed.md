- **A `spec-kitty consolidate` re-run after a fully rolled-back attempt trusts the Mission branch as it stands** (#7626). **Before:** once a refused attempt was fully rolled back, every later run was a resume that trusted only the first attempt's Mission branch. A conflict the operator resolved on the Mission branch between attempts stayed refused as `un-attributable`, even after a lane merged it and was approved again. **After:** such a resume reads the Mission branch before its first change, as a fresh run does. A resume of an interrupted run still trusts only the snapshot it took before its own changes.
