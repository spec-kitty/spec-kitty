- **`spec-kitty consolidate` no longer refuses a lane as stale for a change the lane already contains** (#7311). **Before:** the stale check diffed the Mission branch from a single merge base, which on a lane that depends on another lane could be an older base, so the dependency's change looked missing and the lane was refused. **After:** a Mission-branch path counts as overlapping only when a commit the lane does not contain changed it (a merge counts only for what its own resolution introduced). A genuine overlap still refuses, and a failed probe falls back to the stricter merge-base diff.
