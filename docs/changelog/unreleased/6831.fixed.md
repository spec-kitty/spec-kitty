- **`spec-kitty doctor event-logs` now reclaims run directories and Op-scoped glossary logs that link to no Mission it can find** (#6831, #6739). **Before:** both families were reported `Mission not found` and kept forever, so `.kittify/` kept growing: a run whose `feature-runs.json` entry was replaced or removed, and the `profile-invocation-<id>.events.jsonl` logs that are most of `.kittify/events/glossary/`. **After:** a run whose own record names its Mission by slug follows that Mission's lifecycle; a run that names no Mission at all is judged on age alone (`past retention; no Mission recorded`); an Op-scoped log is kept while its Op is open (`Op is open`) and eligible once it completes (`past retention; Op completed`), or judged on age when no record of the Op exists (`past retention; no Op recorded`). Both limits still apply, locks still win, and a run whose *recorded* Mission this checkout cannot resolve is still kept as `Mission not found`. **What to do:** nothing; re-run `spec-kitty doctor event-logs` to preview, then `--apply`.
