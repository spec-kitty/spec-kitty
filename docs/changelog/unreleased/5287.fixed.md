- **A Mission branch that exists only on a remote now gets one complete, truthful recovery path** (#5287). **Before:** on a fresh or single-branch clone, `spec-kitty agent tasks status` failed with `STATUS_SURFACE_REF_UNREADABLE` and no next step, and the coordination messages said the checkout "has not fetched" the branch, always named `origin` and left out the step that creates the local branch. **After:** when this clone's remote-tracking ref shows a remote holds the branch, the status read refuses with `STATUS_SURFACE_REF_REMOTE_ONLY`; otherwise the unreadable-ref error adds the same steps as a hedged hint. `doctor coordination`, the coordination refusals and the status read all print one set of steps: fetch the branch from the remote that owns it (when needed), create the local branch, then run the coordination doctor.
