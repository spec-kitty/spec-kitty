- **`spec-kitty doctor workspaces --prune` deletes a landed branch by compare-and-swap** (#7212). **Before:** after proving a branch's tip landed, the prune compared the tip and then deleted with `git branch -D`; a branch that moved in between lost the new commit. **After:** the delete itself is bound to the tip the prune approved (`git update-ref -d <ref> <expected>`), so a branch that moves while the delete runs is kept and reported as `BRANCH_MOVED`. A branch that is a symbolic ref is deleted as itself, never through to the ref it points at, as `git branch -D` always did. The report, the recreate command and the `--force-recreate` / `mission close --discard` deletes are unchanged.
