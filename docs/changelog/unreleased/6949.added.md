- **An optional companion wheel, `spec-kitty-services`, installs the service binaries with the CLI for offline use** (#6904). **Before:** the CLI fetched each pinned service binary from its `spec-kitty-events` release on first use, so a first write needed network access or a prepared `SPEC_KITTY_SERVICE_ASSET_DIR`. **After:** `pip install "spec-kitty-cli[services]"` also installs `spec-kitty-services` of the same version, whose platform wheel carries the pinned write and charter service builds for linux x86_64 and aarch64 (glibc 2.39 or newer), Apple Silicon macOS and Windows x64. The CLI prefers it over its cache and still checks every byte against its own pin; any other host gets a binary-free wheel and keeps the first-run fetch. The `spec-kitty-cli` wheel itself still ships pins only, and the events read service never ships. **What to do:** nothing, unless you want offline installs; then install the extra ([ADR 2026-10-29-1, Amendment 2026-10-31](../adr/4.x/2026-10-29-1-the-events-domain-and-its-java-services-live-in-spec-kitty-events.md)).
