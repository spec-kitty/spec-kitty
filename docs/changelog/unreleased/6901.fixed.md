- **`doctor skills` and `doctor tool-surfaces` no longer report a project healthy when they checked nothing** (#6891). **Before:** a `.kittify/config.yaml` with no `agents.available` list — the legacy every-agent fallback (#6501) — printed `all manifest entries healthy (0 file(s))` and `all surfaces healthy (0 checked)` at exit 0, claiming health over an empty examined set while `doctor command-files` reported real problems on the same tree. **After:** both summaries say `no stated agent list (every agent is available) — nothing to check`, name what was not examined and point at the missing `agents.available` list; a project that states its agent list keeps the healthy line with a real count, and every `--json` key, exit code and `--fix` behavior is unchanged. **What to do:** to have the CLI check your surfaces, state the agents you use in `.kittify/config.yaml`.
