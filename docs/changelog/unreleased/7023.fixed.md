- **`spec-kitty upgrade --dry-run` now heads its migration list "Migrations that would be applied:" instead of a green "Migrations applied:"** (#6234). **Before:** a preview printed the `DRY RUN - No changes were made` panel and then the same green `Migrations applied:` list with a `✓` on each migration it would have run, closing with "no changes applied" — so the output said nothing had been applied and that two migrations had. **After:** a dry run heads that list `Migrations that would be applied:` and marks each entry with `→`, while a real run keeps `Migrations applied:` with `✓` unchanged; a dry run with nothing pending still prints no list at all. No migration selection, ordering, write or JSON behavior changes.
