- **`agent action implement --profile` is recorded on the implement claim** (#7159). **Before:** the first claim of a work package in a fresh code lane recorded the bare `--agent` (for example `claude`), so `move-task --to approved` refused a same-tool reviewer under another profile with `REVIEW_NOT_INDEPENDENT`, and re-recording the full identity later needed a return to `planned`. **After:** the claim records the structured implementer actor with the `--profile`, and an unforced `move-task --to for_review --agent <tool>:<model>:<profile>` by the same tool fills in what the claim did not record (never what it did), so a reviewer under another profile approves while the implementer's own identity is still refused.
