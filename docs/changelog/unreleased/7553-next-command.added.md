- **`spec-kitty next` names the command to run next in a new `next_command` field** (#7553, #5929). Read-only envelopes carry it (the advance command, `spec-kitty accept` or `spec-kitty consolidate`), and so do the blocked answers of a finalized board: `accept` for `MISSION_AWAITING_ACCEPTANCE`, the `agent action` command that resumes a busy work package for `BOARD_STEP_NOT_DISPATCHABLE`, and for `LANES_MANIFEST_MISSING` `finalize-tasks` before execution has begun and `doctor mission-state --fix` after. The human output prints it as a `Next:` line.
