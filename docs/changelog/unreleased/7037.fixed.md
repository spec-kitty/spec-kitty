- **A scope-only pull request no longer makes both heavy CI legs collect a test universe no selected gate reads** (#7001, #6994). **Before:** since #6994 a leg ran only the gates the diff touched, but its shared test-universe pre-step still asked about the leg's whole partition, so a docs-only PR paid a full `pytest --collect-only` of the test tree on both legs (89–233 s cold on CI). **After:** `collect_universe_prestep consumers` takes `--gates-file` (default `SK_BATTERY_GATES_FILE`) and answers for the gates the diff selected; a leg whose selected gates hold no collecting test skips every universe step, while a leg that collects still collects the whole tree. **What to do:** nothing; no file, full mode or an unreadable file behaves as documented in [CI gate mechanics](../development/reference/ci-gate-mechanics.md#what-a-scope-only-leg-skips).
