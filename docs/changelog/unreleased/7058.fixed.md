- **Project detection stops at `GIT_CEILING_DIRECTORIES`, and `make test-fast` stays green when the temp directory sits inside a git repository** (#7022, #5356, #7058). **Before:** `locate_project_root` and the plain-`.git` fallback of `find_repo_root` walked past the ceiling that git and `resolve_canonical_root` honor, so a directory below it resolved to the checkout above, and on a host whose temp directory lived inside any git work tree 18 fast-tier tests failed (lock fallback, lanes rebuild, the non-repository git probe, status actors, read-only-home startup) while CI stayed green. **After:** the three walks read the ceiling through one helper that ignores relative entries as git does, and the test harness lists the run's basetemp and isolated home as ceilings, replacing the `tests/status/` fixture that ran `git init` in every escaping `tmp_path`.
