- **An advancing `spec-kitty next` says when it materialized the coordination worktree.** **Before:** a `next --result` run on a coordination Mission whose worktree was missing or empty recreated it without a word. **After:** the human output prints one line, `Materialized the coordination worktree for <mission> at <path>.`, before the decision, and `--json` (and the orchestrator API's `answer-decision` `data`) carries `remediation: {"kind": "materialized_coordination_worktree", "path": "<path>"}`. Nothing is printed or added when nothing was materialized, in query mode, or for a Mission that has landed, whose coordination worktree `next` no longer recreates. Orchestrator API contract `1.27.0`, a purely additive field.
