- **An artifact with no authored id is skipped by the offering catalog** (#4856). **Before:** the catalog fell back to the filename stem for its identity, the one remaining spot that inferred identity from a cosmetic kebab slug. **After:** identity comes from the authored `id` alone; an artifact that declares none is skipped. **What to do:** nothing.
- **`load_org_pack` honors a declared `pack_drg` pointer** (#6059). **Before:** the org-pack runtime loader always read `drg/fragment.yaml`, so an org pack pointing `pack_drg` elsewhere loaded the wrong file (or nothing). **After:** the pointer wins and the convention path is only the fallback when it is absent. **What to do:** nothing.
- **`section:*` prompt stanzas come from the one fetch-stanza composer** (#3093). **Before:** the action-critical section renderer hand-rolled the pair and emitted `When you …` lines that did not match the closed prompt-governance lead-in set. **After:** it delegates to the canonical composer, so every stanza is normalized. **What to do:** nothing.
- **The runtime prompt path renders the SPDD/REASONS block** (#5129). **Before:** `spec-kitty next` inserted the built-in template raw, so the agent-facing prompt showed the `<!-- spdd:reasons-block -->` marker comments verbatim, and with SPDD inactive the block that should have been removed. **After:** it applies the same renderer the slash-command and skills paths use. **What to do:** nothing.
- **A `$HOME` with a `..` segment or a relative `$HOME` no longer breaks every command** (#6176). **Before:** the global reporting anchor was built from the unnormalized `Path.home()`, so the runtime bootstrap died with `ValueError: Root requires an identity and an absolute normalized path` (exit 1). **After:** the anchor inputs are normalized first. **What to do:** nothing.
