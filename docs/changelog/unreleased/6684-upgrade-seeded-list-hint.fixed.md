- **`spec-kitty upgrade` now warns about an activation list a *released* `default` preset wrote** (#6684). **Before:** `4.0.0rc8_promote_interview_selections` recognized a machine-written list only by equality with today's full in-force set, so a project seeded from an older release's preset (19 directives at 3.2.6rc1, 38 shipped now) got no warning and stayed blocked in `charter synthesize`/`implement`. **After:** it also recognizes the released preset lists the pack cutover already compares against - the preset alone, and the preset plus the interview ids it lacked - says the list is machine-written, and names both narrowing commands. Nothing is written or narrowed: the #6684 ruling keeps upgrade report-only, and a hand-picked list that merely overlaps a preset, or names an artifact no longer in force, is left alone. **What to do:** nothing; to narrow, run `spec-kitty charter interview --narrow-activation` or `spec-kitty charter activate <kind> <id> --only`.
