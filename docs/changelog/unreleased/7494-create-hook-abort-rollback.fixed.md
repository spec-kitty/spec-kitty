- **`agent mission create` rolls back fully when a pre-commit hook aborts a coordination create** (#7494). **Before:** with `--topology coord` or `lanes_with_coord`, a hook that aborted the create commit left `kitty-specs/<slug>-<mid8>/meta.json` naming the coordination branch the rollback had deleted, the resume probe reported `MISSION_RESUME_MALFORMED`, and the partial Mission had to be removed by hand. **After:** once the rollback deletes the coordination branch it minted, it also removes the new, untracked scaffold, so the probe reports `not_found` and the create can run again after the hook is fixed. A `single_branch` create keeps its resumable scaffold, and a `MissionCreated` persistence failure still keeps its scaffold for the probe.
