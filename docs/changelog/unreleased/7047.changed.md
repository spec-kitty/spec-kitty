- **Removing `pr:pause-ci` restarts CI on the PR** (#7019, #7047). **Before:** the required workflows did not trigger on a label change, so a paused PR kept its paused result until someone pushed a new commit. **After:** removing the label starts a full CI run on the PR's current head; adding it reports the paused state again; adding or removing any other label starts a no-op run that skips every job and neither cancels nor replaces the real run.
