- **The lifecycle event vocabulary now has one owner** (#6447). **Before:** `specify_cli/status/lifecycle_events.py` hand-copied the twelve event-type strings from `spec-kitty-events`, so the copy could drift from the package that owns it. **After:** the twelve names are imported from `spec_kitty_events`.
- **`spec-kitty doctor mission-state --audit` no longer flags `schema_version` in `status.json` as `UNKNOWN_SHAPE`** (#6111). **Before:** the audit's `status.json` key list was hand-written and lacked `schema_version`, so every reducer-written snapshot produced an info-level finding (~90 on the corpus). **After:** the known keys are derived from `StatusSnapshot`, the snapshot writer, so the reducer's own keys are known.
