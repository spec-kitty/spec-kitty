- **`spec-kitty consolidate` refuses a commit made between two approvals on a lane** (#7403, #5721). **Before:** a commit made after one work package's approval and before the next one started landed, because the later approval stamp reached it. **After:** each approved work package covers only its recorded window, and such a commit is refused with `LANE_MOVED_AFTER_APPROVAL`, naming the commit and the work package approved before it, to send back and approve again. A commit no newest approval precedes (work abandoned before a rewind) gets its own text, since approving again cannot cover it. A commit another lane's approval stamp reaches stays exempt, as do a canceled work package's own commits and those of a `--dependency-ref` merged before the window opened.
