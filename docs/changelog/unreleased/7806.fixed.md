- **`agent action review` works in a teammate's clone where the lane branch exists only on the remote** (#7806). **Before:** a clone holding the lane only as `refs/remotes/<remote>/<lane>` refused the review with `LANE_AUTO_REBASE_FAILED ... is not a local branch`. **After:** the review creates the local lane branch from the owning remote's tracking ref, with `--track`, and carries on. With the origin check off, unreachable or ambiguous it still creates the branch from the last-fetched ref and prints a warning that it was not refreshed; an ambiguous owner never picks a remote. A recorded lane work tip that the tracking ref does not contain refuses with `DESTROYED_LANE`, and a clone with no ref for the lane still refuses. The coordination branch (#5936), the lane base lookup and the review now share one owning-remote rule.
