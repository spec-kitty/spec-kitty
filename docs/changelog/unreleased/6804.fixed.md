- **The `grep_absence` acceptance verdict no longer counts a stale `.pyc` as still present with blank evidence** (#6804, #6761). **Before:** the invariant ran plain `grep -n`, so a stale `.pyc` under `__pycache__/` still containing the pattern made GNU grep >= 3.5 print `binary file matches` on stderr and exit 0 with empty stdout; the matcher recorded `still_present` with the evidence `grep found matches: ` (blank). **After:** grep runs with `-I`, so only text files are judged and a binary sidecar alone records `confirmed_absent`; on a match where stdout is empty (exit 0), the non-empty stderr lines are recorded as the evidence, with a never-blank fallback, keeping the 5-line cap. Still one grep subprocess per invariant; no CLI or schema change.
