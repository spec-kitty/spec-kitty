- **`spec-kitty doctor workspaces --prune` proves each destructive step first** (#7211, #7212, #7214; ADR `2026-11-06-1`). **Before:** a branch that moved between the tip check and `git branch -D` lost its new commit; a commit only the destroyed reflogs held could be collected by `git gc`; and a fork clone could never prove a landing, because only `origin` was read. **After:** `--remote <name>` (default `origin`) names the proving remote; commits only a reflog held are kept under `refs/spec-kitty/discarded/reflog/<sha>` unless their content is already on that remote's primary; and the branch is deleted by compare-and-swap, so a moved branch is kept as `BRANCH_MOVED`. `--json` gains `remote` and `kept_commits`.
