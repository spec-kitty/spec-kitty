- **`spec-kitty doctor workspaces --prune` proves every destructive step before it takes it** (#7211, #7212, #7214; design #7264, ADR `2026-11-06-1`). **Before:** the prune compared a branch tip and then ran `git branch -D`, so a branch that moved in between lost its new commit; it destroyed the worktree `HEAD` reflog and the branch reflog, so a commit made while detached or dropped with `git reset --hard` could be collected by the next `git gc`; and it proved a landing only against `origin`, so in a fork clone whose canonical repository is `upstream` every worktree stayed `not_landed`. **After:** one guard entry discharges each proof obligation first: the landing ref belongs to the remote you name with the new `--remote <name>` option (default `origin`, an unknown or blank name is refused) and still absorbs the tip; the worktree is clean, at that tip, and no process runs in it; every commit only a destroyed reflog reached is recorded under `refs/spec-kitty/discarded/reflog/<sha>` (only local refs count as keeping a commit alive, and a commit `git cherry` proves already on the landing ref is not recorded, so a rebase landing adds no refs); the worktree is removed without `--force`; and the branch is deleted by compare-and-swap at the proven tip, so a branch that moves is kept and reported as `BRANCH_MOVED`. The report prints a `reflog-only commit kept at` line, and `--json` gains `remote` and each pruned entry's `kept_commits`.
