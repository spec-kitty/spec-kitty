- **`accept` no longer suggests `mkdir -p` for a missing build-layout directory** (#7512). **Before:** when `src/`, `tests/` or `docs/` was missing, the path-convention text listed `mkdir -p src/` among its actions, and creating the empty directory made the check pass. The `--lenient` warning did not mention `project.path_conventions`. **After:** both texts name the `project.path_conventions` remap for those paths and suggest `mkdir -p` only for a Mission artifact path such as `contracts/`. Which paths are checked, and whether a missing path blocks, is unchanged.
