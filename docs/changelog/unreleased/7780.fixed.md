- **A stale-lane refusal at `spec-kitty consolidate` can now be acted on** (#7755, #7754). **Before:** when a lane's in-run auto-rebase stopped on a conflict with a sibling lane consolidated ahead of it, the refusal dropped the halt reason and told the operator to incorporate the Mission branch, which the run's rollback had just restored without the sibling's change, so every re-run refused the same way; and its first command, `spec-kitty agent action implement`, refuses an approved work package. **After:** the refusal gives the auto-rebase halt reason, names the sibling lane and its branch, and prints a route an approved work package can take: reopen it with `move-task <WP> --to planned --review-feedback-file <file>` (a re-review), re-enter it with `implement`, merge the named sibling branch in that checkout, resolve and commit, have it approved again, then re-run `consolidate`.
