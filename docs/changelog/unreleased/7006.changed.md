- **`spec-kitty next` writes each Op lifecycle record to its own file** (#7003). **Before:** every `started` and `completed` record was appended to the one shared `kitty-ops/lifecycle.jsonl`, so two pull requests that each ran `next` conflicted at its end and the merge queue dropped the second. **After:** each record is a new `kitty-ops/lifecycle/<ulid>.json` that no other branch writes, so the two pull requests merge with plain git. `kitty-ops/lifecycle.jsonl` is still read, after which the record files follow in time order, and is never written again; the orphan report and pairing rate are unchanged. **What to do:** nothing; commit the new `kitty-ops/lifecycle/` files as you committed the log.
