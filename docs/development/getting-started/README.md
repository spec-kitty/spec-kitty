# Getting started (contributors)

First stops for a new contributor or a prospective co-maintainer: how a full
mission session is primed and run, and how to keep several checkouts isolated on
one machine while you work.

- [Onboarding run](onboarding-run.md) — a reusable priming prompt and 12-step SDD cadence for onboarding a prospective co-maintainer.
- [Isolated dev environments (Shadow Clones)](isolated-dev-environments.md) — run several standalone checkouts on one machine without cross-mission pollution: a clone-local `.venv` plus a clone-local `SPEC_KITTY_HOME` state root, machine-global CLI left intact.
