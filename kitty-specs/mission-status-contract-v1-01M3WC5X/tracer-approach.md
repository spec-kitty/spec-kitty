## Rules of the road

- Red first: each WP's first commit is a failing test or planted fixture, red on the planning base
  and green on the final commit (C-010); the reviewer verifies both.
- Named gate files only; no full architectural, end-to-end or `make test-full` run in mission
  work (`NO_FULL_HEAVY_SUITES_IN_MISSION`). Commands and counts are recorded for the PR.
- Never call `materialize`, never run a command that writes status or state while investigating
  (tracer friction F-1). Use `materialize_snapshot` or `read_events`.
- Every cited path or symbol is checked against `git ls-files` and the file text before it is
  written; no stale line numbers.
- One PR, draft until the design is acknowledged on #5528; the tag push after merge is a
  close-out step, not a follow-up issue.
