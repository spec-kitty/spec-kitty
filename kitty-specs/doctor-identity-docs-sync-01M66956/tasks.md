T002 Rewrite the Step 2 state list in `docs/migrations/mission-id-canonical-identity.md` to the live five states (`assigned`, `pending`, `legacy`, `orphan`, `residue`) with the live definitions, mirroring the `spec-kitty doctor identity --help` wording that `docs/api/cli-commands.md` carries
T003 Rewrite the Step 2 and Step 4 JSON samples from the live `--json` contract (grounded in the fixture run recorded in research.md): `summary` with all five states, `missions[]` rows with `path`, `slug`, `mission_id`, `mission_number`, `state`, `error`, `residue_reason`, plus `duplicate_prefixes`, `ambiguous_selectors`, `fail_on_triggered`, and the conditional `residue_remedies`

T005 Run the structural test to green; run the docs gates (`docs_index --write`, `freshen_adr_inventory`, `check_docs_freshness --ci`, `tests/architectural/test_no_legacy_terminology.py`) and fix any fallout from the page edit
T006 Add the `[Unreleased]` changelog entry in `docs/changelog/CHANGELOG.md` (bold impact-first lead with `(#6760)`, before/after, under 1,200 characters)
