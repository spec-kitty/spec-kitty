# Design decisions — single-branch-gate-fallout

- **[2026-10-18][specify] Planning commit = repo tip at finalize time.** `finalize-tasks` captures the current branch tip into `planning_commit_sha` in the same write as `lanes.json` (`mission_finalize_planning_pin._preserve_or_capture_planning_commit_sha`, ADR 2026-07-29-1 / FR-009), so the fixture passes `HEAD` at `compute_and_write_lanes` time. The window `planning_commit..main` then covers the fixture's finalize commit and both WP code commits.
- **[2026-10-18][specify] Distinct seed actors.** `_seed_wp_approved` uses `implementer-ivan` for the implementing hops and `reviewer-renata` for `in_review`/`approved`, matching the terminus fixture `_approve_events` (#5939 follow-up `1803d146`).
- **[2026-10-18][specify] Scenario 6: align the wording, do not assert the code.** The non-owned `move-task --json` envelope omits `error_code` by a pinned contract (`test_context_error_envelope_is_opt_in`). Aligning the `SINGLE_BRANCH_IMPLEMENTATION_MISSING` message with `for_review_gate` and the consolidate axis ("no implementation commit") unifies the vocabulary and leaves the scenario and its ledger note true. Decision moment 01M57KRSRE76R1AW5YEAFKMP8C.
- **[2026-10-18][implement] Post-spec squad folds.** The wording is now independent of the target lane ("cannot move into review"), because the gate also fires for `--to approved`. The unit test asserts code and phrase together. The fixture records `rev-parse main` and passes `actor=implementer-ivan` to the real `implement()` claims: the default `implement-command` is a generic actor that `latest_implementer_event` skips, so the real claims contributed no identity before.
- **[2026-10-18][implement] Audit result (FR-004).** A sweep of 163 candidate files (out-of-matrix dirs included) found no other red caused by #5939. Finding outside scope: `single-branch.feature` "A stray file in the checkout is never committed" stays green, but the move-side gate now refuses before `_mt_commit_lane_deliverables`, so the scenario no longer exercises the no-sweep guard. Reported in the PR as a follow-up, not changed (C-003).
