- 2026-09-19 — Decision: non-ASCII mission/feature names are **rejected explicitly** (not transliterated). Alternatives: best-effort transliteration to ASCII. Rationale: charter Identifier Safety Rules require deterministic ASCII-allowlist identifiers; transliteration is lossy, locale-dependent, non-reversible and collision-prone; explicit rejection is deterministic and matches the mission's fail-closed philosophy. (decision 01M2WJE53KMFBGEJX8JMFT71EE, #4720)
- 2026-09-19 — Decision: one mission for the whole umbrella-#2899 open remainder rather than per-issue point fixes. Alternatives: two P2 point fixes; seam-only mission. Rationale: the crashes are one defect class; a shared seam + construction gate closes it once instead of re-discovering it on the next command.
- 2026-09-19 — RESOLVED (post-spec squad): CLI presentation = a **global Typer error hook**, NOT an opt-in decorator. Alternatives: `@handle_domain_errors` decorator (opt-in). Rationale: a decorator is forgettable (the exact omission that bit #4642) and its only gate is gameable decorator-presence; a global hook cannot be forgotten, is trivially gate-checkable (assert registered), and — scoped to a single domain base with everything else re-raised — closes every command boundary at once (resolves #4724's 14 call sites for free) without masking real bugs. (architect-alphonso H1)
- 2026-09-19 — RESOLVED (post-spec squad): the kernel guarded-read primitive is **format-agnostic** — it wraps a caller-supplied parse callable + caller-declared caught-exception tuple, always covers OSError+UnicodeDecodeError, and collapses them into ONE typed domain-read base. Alternatives: a primitive that does read+decode+schema-validate itself. Rationale: a kernel primitive CANNOT import runtime's pydantic `WorkflowFile` model (violates `kernel <- … <- specify_cli`); decode/schema knowledge (yaml, pydantic, tomllib) must stay in the caller's layer. `meta_decode.decode_meta` becomes the JSON specialization layered on the primitive. Kernel imports no schema/validation library. (architect-alphonso C1/M2)
- 2026-09-19 — RESOLVED (post-spec squad): FR-013 consolidation makes the legacy typed errors (`MetaDecodeError`, `MissionMetaReadError`, `DecisionIndexReadError`, `CorruptLanesError`+`MissingLanesError`, `AgentConfigError`, `UnsafePathSegmentError`, `IntakeFileUnreadableError`) **subclasses of the shared base**, never flat-replaced. Rationale: paula-patterns census found ~85 downstream `except` sites (many tuple-catches, some coupled pairs) across ~30 modules; a flat type change breaks them all and re-opens the class off-scope. A full `except`-site caller census (src + tests) precedes any raised-type change. (paula-patterns CRITICAL-1)
- 2026-09-19 — RESOLVED (post-spec squad): canonical handled-domain-error exit code = **1** (matches shipped #4600/#4642); Typer *usage* errors keep exit 2 and must NOT be swallowed by the hook. `mission close` routes through the hook → exit 1; #4720 name validation stops raising `typer.BadParameter` (which bypasses the hook and forces exit 2 / stderr) and raises a domain error → exit 1 + JSON envelope on stdout. The existing bespoke emitters (next/accept/merge) fold into the hook (C-002 single authority), normalizing to exit 1 as a deliberate, tested change. (reviewer-renata H3, architect-alphonso H2/M3)
- 2026-09-19 — RESOLVED (post-tasks squad): `GuardedReadError.__init__` is **positional-compatible** (`*args, path=None, reason=None`), not required-kwargs — 3 subclasses pass a positional message string (would `TypeError` at ~85 sites otherwise). MRO: `GuardedReadError(Exception)`; `UnsafePathSegmentError(GuardedReadError, ValueError)` AND `MetaDecodeError(GuardedReadError, ValueError)` (both have load-bearing `except ValueError` catchers). (brownfield C1/H1)
- 2026-09-19 — RESOLVED (post-tasks squad): the `next_cmd.py` bespoke-emitter fold is **deferred** (next_cmd.py owned by no WP; folding would exceed WP01 ownership) and recorded as the D4 future-consistency follow-up; the "merge emitter" fold target was a phantom (no such emitter exists) and struck. WP01 registers the global hook only. (brownfield H2/M1)
- 2026-09-19 — RESOLVED (post-tasks squad): WP02 also re-parents `UnknownWorkflowError` and guards `workflow.py:85` `_copy_workflow` `read_bytes`; WP08's gate scans the real read modules (`agent/release.py`+`release/payload.py`, not `agent/status.py`) with a scan-derived shrink-only floor; WP02/WP03 `dependencies:[WP01]` restored → lanes recomputed (lane-b..g dep lane-a). (anti-laziness CRITICAL-1/HIGH-1/2/3)
- 2026-09-19 — RESOLVED (post-spec squad): FR-012 hardening preserves each reader's **missing-vs-corrupt** contract — absent input keeps its current `None`/empty return (callers branch on it, e.g. `runtime_bridge` None-fallback to prose parsing); only decode/parse/schema failure routes to the typed error. The masking broad `except Exception` at `runtime_bridge.py` (call at :1024, catch at :1034) is replaced by the typed seam WITH a companion assertion that no other previously-swallowed path in that block changes behavior. Audit-tail readers are tested through their real command entry point (finalize-tasks for wps_manifest, etc.), not reader-level only. (paula CRITICAL-2/HIGH-1, reviewer-renata H2)
