## Work Package WP01: Real `--mission` on the three corpus walks (Priority: P1) 🎯 MVP

**Goal**: Give `migrate backfill-provenance`, `migrate charter-encoding` and `migrate rebaseline-dossier-hashes` a real, working `--mission` that resolves through the canonical selector resolver and narrows each command's existing discovery walk to one Mission — while `charter-encoding --mission` skips the global charter store and reports it, the corpus-wide default stays byte-identical, and `rewrite-opposed-by` / `repin-hooks` stay reject-only.
**Independent Test**: Build a two-Mission fixture, run each of the three commands with `--mission <handle>` for one Mission, and assert the target Mission's file changed while the other Mission's file is byte-identical; then run each without `--mission` and assert both Missions are processed.
**Prompt**: `/tasks/WP01-migrate-real-mission-scoping.md`
**Requirement Refs**: FR-001, FR-002, FR-003, FR-004, FR-005, FR-006, FR-007, FR-008, NFR-001, NFR-002, NFR-003, NFR-004, C-001, C-002, C-003, C-004

### Included Subtasks

T001 Write the red CLI-surface tests in `tests/cli/test_mission_agnostic_flag.py`: the reject set is exactly the two non-Mission commands, and the three scoped commands declare a visible `--mission` (so `--help` advertises it) instead of rejecting it.
T002 Write the red scoping-contract tests in `tests/migration/test_migrate_mission_scoping.py`: per-command two-Mission isolation, mission_id/mid8/slug handle equivalence, unknown-handle fail-closed, unscoped corpus default, `--dry-run` writes nothing, second-run idempotency, and the `charter-encoding` global-store exclusion in both renderings.
T003 In `src/specify_cli/cli/commands/migrate_cmd.py`, add `_scoped_mission_slug(...)` (delegating to `resolve_mission_handle`), declare a real `--mission HANDLE` option on the three commands, drop `cls=CorpusWideCommand` from them, and update their docstrings, usage examples and exit-code lists.
T004 [P] Narrow `src/specify_cli/cli/commands/migrate/backfill_provenance.py` discovery: `_collect_matrix_paths(repo_root, mission_slug=None)` scopes the mission loop (keeping the `placement_seam` read) and `run_backfill_provenance_migration(..., mission_slug=None)` reports the scope on `BackfillSummary`.
T005 [P] Narrow `src/specify_cli/cli/commands/migrate/charter_encoding.py` discovery: `_collect_charter_files(project_root, mission_slug=None)` scopes to one Mission's `charter/` and omits `.kittify/charter/`; record `global_store_excluded` on `_ScanSummary` and report it in both `_emit_json_summary` and `_emit_human_summary`.
T006 [P] Narrow `src/specify_cli/dossier/rebaseline.py` discovery: `iter_recorded_snapshot_files(root, *, mission_slug=None)` and `rebaseline_recorded_snapshots(..., mission_slug=None)` filter by path-derived mission identity (dossier dir slug or owning `kitty-specs/<slug>` source dir), never by reading each candidate.
T007 Report the scope in `migrate_cmd.py` payloads/summaries (`"mission"` on `backfill-provenance` and `rebaseline-dossier-hashes`, a scope line in both human summaries) and update the docs the change touches: the `[Unreleased]` changelog entry and the regenerated `docs/api/cli-commands.md` section for the three commands.

### Implementation Notes

- Resolution happens once, in the CLI, and the backends receive a canonical `mission_slug: str | None`. Never re-parse a handle in a backend (`C-002`).
- `charter-encoding --project-root` remains: resolve the handle against `project_root.resolve()`, the same root the walk uses.
- Scoping narrows *discovery*; it must not change what the existing code does to a file it finds, and it must not add a corpus read in order to filter (`NFR-001`).
- Exit codes keep their meaning: ambiguous/backup-collision still exit 1 for `charter-encoding`; a scoped run over a Mission with no matching file is a valid exit-0 no-op.
- Additive JSON only: no existing payload key changes shape.
- Regenerate only the CLI reference the diff changes and verify with `uv run python -m scripts.docs.check_docs_freshness --ci` (errors=0) rather than trusting a full rebuild.

### Parallel Opportunities

T004, T005 and T006 touch three disjoint modules and can proceed in parallel once T003 lands the shared parameter shape. T001/T002 are authored first (red) and are independent of each other.

### Dependencies

- None (single starting package).

### Risks & Mitigations

- **A declared-but-ignored `--mission`** would recreate the silent no-op #5294 closed: mitigated by the per-command byte-identity isolation test (target file changes, sibling file does not).
- **Over-narrowing `backfill-provenance`** to a raw `kitty-specs/<slug>/` join would miss a coordination-homed matrix: mitigated by keeping the `placement_seam(...).read_dir(ACCEPTANCE_MATRIX)` read inside the narrowed loop.
- **`charter-encoding` treating a pre-existing global-store problem as its own failure** would fail a valid scoped run: mitigated by computing the scoped exit code from the Mission-scoped files only, and by the global-store byte-identity + no-`.bak` assertions.
- **`rebaseline` reading every snapshot to filter** would violate `NFR-001`: mitigated by path-derived identity and a comment explaining why the recorded `mission_slug` field is not consulted.
