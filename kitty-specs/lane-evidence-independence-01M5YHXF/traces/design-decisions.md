# Design decisions

- **[2026-10-27][specify] Independence keeps the #5939 identity (`tool:model:profile`).** The recorded role is stamped from the target lane, so a role comparison could never detect self-approval; operator chose "keep #5939 identity" over profile-else-tool, strict profile, or a new role field.
- **[2026-10-27][specify] `move-task --force` keeps bypassing evidence; accept and consolidate stay strict.** Decision 01M5YHYFRJPTE0SQ9V7SWGK26J; keeps the docs-only route to `approved` and the #5939 test shape.
- **[2026-10-27][specify] Planning lanes are checked too.** Operator ruling; window `planning_commit_sha..target_branch`, bookkeeping paths excluded.
- **[2026-10-27][plan] Evidence window base is `lanes.json planning_commit_sha`.** Fixed point that survives a resume after lanes landed; `merge-base(target, lane)` rejected because it empties after landing. Tree diff, so commit-then-revert is no evidence.
- **[2026-10-27][plan] Attestation recordable from accept and consolidate.** Accept now refuses first, so consolidate-only would make a docs-only WP unlandable.
- **[2026-10-27][review] Residual: the planning window counts content merged into a lane.** A hollow WP passes if its lane merges in content someone else committed to its owned paths (needs an out-of-map edit; #5939's single_branch window has the same limit). Disposition: record in the ADR amendment (WP04) and the PR; candidate follow-up is to read only the lane's own non-merge commits.
- **[2026-10-27][review] A no-implementation attestation counts only while the WP stays in approved/done.** Operator ruling after WP02 review cycle 1 showed a stale attestation lifting IMPLEMENTATION_MISSING for reopened, re-approved hollow work; any later non-migration move out voids it, matching how the other two attestations are bounded.
- **[2026-10-29][review] A placeholder approver (no `--agent`, recorded as `user`) is not an independent reviewer, and the move refuses it too.** WP03 review cycle 1 showed a self-approval without `--agent` landing as reviewed at every surface; operator ruled it refuses at the move (unforced) as well as at accept/consolidate. The implementer side already excluded generic placeholders; the approver side now uses the same set.
- **[2026-10-29][review] An unforced `in_review -> approved` after a forced `for_review` is not re-checked for evidence at the move.** Consistent with the force ruling; accept and consolidate refuse it. Record in the ADR amendment.
