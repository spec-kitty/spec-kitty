## Objective

Stop `spec-kitty implement WP##` from silently clobbering a repository's own
`.git/hooks/pre-commit` (#4895, P0). `.git/hooks` is shared by the main checkout and every
worktree, so the current unconditional `os.replace` disables the operator's commit-time
checks repo-wide, untracked and unrecoverable. Detect a **foreign** hook by signature,
back it up via the WP01 `backup_before_overwrite` helper, install the guard hook, and
surface the backup path. A spec-kitty-signed hook is replaced as today.

## Ground truth (verified on main@d57619a900)

- `policy/hook_installer.py:105-137` `install(repo_root)` renders to a temp file and `os.replace(tmp, hooks_dir/"pre-commit")` at `:125` — no existence/signature check, no backup.
- `:140-166` `install_commit_guard` wraps `install` in `except Exception: return None` (swallows failures).
- `lanes/implement_support.py:177-180` calls `install_commit_guard(workspace_path, repo_root)` unconditionally on every `implement`.
- Mirror the ownership proof already used in the removal direction: `upgrade/migrations/m_2_0_0_retire_git_hooks.py` removes only hooks whose body bears the spec-kitty signature (`# Generated by spec-kitty.`) and leaves foreign hooks alone.

## Contract (see contracts/preservation-contract.md §C-hook)

Hybrid contract = **backup-and-warn + proceed** (workflow-internal; refusing would break the
in-progress implement loop). Foreign hook ⇒ `backup_before_overwrite(hook_path)` → install →
print the backup path. Signed hook ⇒ replace, no backup churn. No pre-existing hook ⇒ unchanged.
