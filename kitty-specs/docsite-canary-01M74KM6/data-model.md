# Data Model: Docsite canary deploy

## Probe (value object)

| Field | Meaning |
| --- | --- |
| `url_class` | one of `own-page-key`, `moved-chain-key`, `live-index`, `readme-key`, `directory`, `root`, `llms`, `retired` |
| `path` | site-relative URL, leading slash |
| `expect` | `page` (200, not a stub), `stub` (200, a stub whose target equals `target`, and `target` serves a page), `text` (200), `gone` (404) |
| `target` | the legacy map's target, for `stub` only |

Invariants: a `stub` probe has a target; the sample has exactly one probe per class; the retired path is in neither the baseline nor the map.

## Outcome (value object)

`probe`, `ok: bool`, `detail: str` (one report line).

## Inputs

- URL baseline: `site/url-baseline.txt` (`moves_ledger.load_baseline`).
- Moves ledger: `site/moves.yaml` (`moves_ledger.load_moves`; chains collapse with `collapse`).
- Legacy map: `site/legacy-redirects.json` (flat object, generated by `site_redirects.py`).

## Workflow inputs

- `docs-pages.yml` `workflow_dispatch.inputs.canary`: boolean, default false.
- `docs-site-build.yml` `workflow_call.inputs.pages-artifact-name`: string, default `github-pages`.
