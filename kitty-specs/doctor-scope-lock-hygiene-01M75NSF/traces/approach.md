# Approach

- Grounding first (`research/code-grounding.md`), read-only, committed before the spec.
- Brief-intake specify: the dispatch brief is the confirmed intent; one Decision Moment for the open scope question.
- Two independent work packages (doctor scope; lock hygiene), each red-first through the pre-existing CLI entry points.
- Prevention over reclamation for the lock (kernel G3 forbids unlinking a lock file).
- Red-on-base proven three ways: the red commit's own run, a scratch worktree at origin/main with only the new tests,
  and (for the terminus pin) base source restored in place.
- Independent review by a separate reviewer agent on the code diff, without the implementer's conclusions.
