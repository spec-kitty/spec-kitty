# Design decisions — consolidation-window-provenance-01M6Y84D

Running log of design choices and rationale (procedure `mission-tracer-files`). The full record is in `research.md`; the binding record will be ADR `2026-11-08-2-work-package-windows-are-recorded-at-the-opening-transition`.

- **[2026-11-08][specify] The window lives on the status event, under one namespaced key.** `policy_metadata.wp_window` holds `open_sha` or a typed `gap`. There is no sidecar or second store, because the event log is the only authority (Decision Moments `window_source`, `window_writer`; ADR `2026-09-29-1-closed-world-refuse-on-mixed-lanes` Decision 2).
- **[2026-11-08][specify] A missing window falls back and is reported, never refused alone.** The approval-stamp bound applies (a degraded window from the claim base), so in-flight Missions keep their verdict. `APPROVAL_STAMP_MISSING` is unchanged (Decision Moment `missing_window_rule`).
- **[2026-11-08][plan] Write on every opening move, read the first.** The pure pipeline cannot know a move is the first without reading history, so it writes on each non-migration entry into `claimed`/`in_progress`, reusing the `lane_head` reading (0 extra git reads). The reader binds to the first such event, mirroring `approval_window_open_stamp`.
- **[2026-11-08][plan] Flat `reconciliation_<unit>.py` modules, not a subpackage.** A subpackage cannot share the facade's name, and a new `__init__.py` would trigger the version-bump rule. Ownership is by directory glob, so the CI module registry needs no edit.
- **[2026-11-08][plan] `ClaimInputs` keeps per-mode quirks in Phase 2.** The extraction is witnessed by the corpus with zero verdict change. Aligning the forecast's excluded set and freezing the resume anchors are separate red-first changes in Phase 4.
- **[2026-11-08][plan] The `blocked` opener asymmetry stays a named window variant.** Unifying it would change closed-world verdicts outside NFR-002, so the ADR maps it rather than removing it.
- **[2026-11-08][plan] No version bump for the `status/__init__.py` re-export.** Operator ruling: the `WP_WINDOW_KEY` re-export carries a changelog fragment only; `pyproject.toml`'s version is not touched (charter standing order 7 wins over the CLAUDE.md `__init__.py` rule).
- **[2026-11-08][plan] The lane's own approval stamps stop exempting its commits on the window path.** Operator ruling, Decision Moment `01M6YAFYHT0RMVZB03THW1WWSE`: windows decide; other lanes' approved tips stay exemption anchors (content inside another lane's reviewed tip). FR-007 and SC-001 state the exception; a dependency-chain fixture pins it. An all-gap lane runs today's check unchanged (FR-023).
- **[2026-11-08][plan] On resume, one frozen claim-time anchor set feeds every anchor consumer.** Operator ruling, Decision Moment `01M6YAFZVZAYR4G20Q2X4PN0FT`: closed world, approved bound, fully-canceled lane and attestation read the same frozen set (FR-015 widened). Each verdict flip is named in NFR-002 with its own red-first test through `consolidate --resume` on the SIGKILL harness (NFR-010).
- **[2026-11-08][plan] The window opens at the window opener, not the first claim ever.** Operator ruling, Decision Moment `01M6YAG16WDVMM37HCJCHAC5YW`: the first claimed/in_progress move after the WP last returned to planned, skipping leading "lane branch missing" openers (written as their own gap reason, not `capture_failed`), ordered by lane topology with log-order fallback (FR-021). Interpretation recorded for review: a review rejection to `planned` (out of `for_review`/`in_review`/`approved`/`done`) is rework and does not reset the window; otherwise the gate would refuse a reworked WP's own earlier commits.
- **[2026-11-08][plan] The spec-kitty-events writer issue is filed now.** Operator ruling, Decision Moment `01M6YAG2HE6Q2XNQMGK6X3MBEK`: spec-kitty/spec-kitty-events#229, linked from FR-006, research R-12 and the ADR concern. The `lane_branch_missing` gap reason postdates the filing and needs a follow-up comment there (operator-authorized GitHub write).
- **[2026-11-08][tasks] One name for the fresh-interpreter smoke test.** Orchestrator decision: the file is `tests/consolidation/test_reconciliation_module_imports.py` (WP10 creates it). WP13, WP14, WP15 and WP21 referred to `test_reconciliation_modules_import.py`, which no work package creates; their text and `owned_files` now use the canonical name.
