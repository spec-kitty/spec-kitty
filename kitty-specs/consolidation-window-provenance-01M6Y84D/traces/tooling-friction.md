Workaround: added them to `.git/info/exclude`. Candidate gap: create could ignore untracked paths outside `kitty-specs/`, or name the `.git/info/exclude` remedy in its refusal.

Candidate gap: the opencode/LiteLLM routing had no fallback model group, so one unreachable endpoint stopped the delegate instead of failing over.

- **[2026-11-08][tasks] A WP prompt writer (Claude Opus) simulated the implementation in a temp directory to "make sure the instructions hold".** That effectively implements the work twice: once while writing the prompt and again in the implement step. It is very wasteful in tokens and wall-clock. The operator flagged it. Disposition: candidate gap. Prompt-writer briefs (and the tasks command contract) should say to verify instructions by reading code and running existing tests only, never by prototyping the change. Applied from here on in this mission's delegate briefs. Filed upstream as spec-kitty/spec-kitty-open-packs#176 so the tasks, tasks-packages, plan and specify prompts carry the rule.

The same check was rerouted to Claude Haiku. Disposition: candidate gap. With deepseek unreachable earlier the same day, TokenFactory reliability is too low to rely on for blocking steps; the opencode route needs streamed or partial output and a fallback model group.
