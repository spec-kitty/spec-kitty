- 2026-10-06 OPERATOR RULING (Stijn, escalated fork 1, origin ahead): split by branch class. Coordination branch at consolidate/accept: REFUSE when local is behind or diverged, naming the commits and the remedy; the gate never mutates the coordination authority. Lane at review: create from origin when no local branch; fast-forward (clean worktree, strict ancestor) when behind; refuse when diverged. Consolidate claim also refuses when an approved lane's origin tip is ahead of the local lane.
- 2026-10-06 OPERATOR RULING (Stijn, escalated fork 2, offline): fail closed + opt-out, "with an env variable to default opt-out of remote/local sync enforcement". No remote / branch never pushed => pass silently. Remote configured but unreachable at P0 gates (consolidate, accept, orchestrator-api consolidate/accept) => refuse, unless opted out. Interpretation recorded: the opt-out (CLI flag, env var as its default) turns every origin-reconciliation REFUSAL at a gate into a printed warning (the fetch is still attempted and reported). Env var name deliberately avoids the dead "sync" vocabulary (CLAUDE.md: never re-enable sync): `SPEC_KITTY_ORIGIN_CHECK=warn` (default `enforce`). Review/implement only warn on unreachable.
