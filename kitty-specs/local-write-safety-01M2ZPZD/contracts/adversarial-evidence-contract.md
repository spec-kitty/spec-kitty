# Contract: adversarial-evidence disposition

Every contested finding raised by a profile-loaded adversarial squad against this mission is
recorded with exactly one disposition; none is silently dropped.

- **accepted** — the finding changed the spec/plan; cite where.
- **changed** — a modified version was adopted; cite the modification.
- **deferred_with_rationale** — not adopted now; record why and where it is tracked (e.g. Non-Goal, follow-up issue).

The live ledger for this mission is in [`../research.md`](../research.md) §"Adversarial Evidence Ledger",
covering the pre-spec squad (architect / paula / debugger / renata) and the post-spec squad
(renata / paula / priti). Any new adversarial pass (post-tasks, pre-merge) appends rows there.
