# Canonical Promotion Contract

The documentation implementation is complete only when:

1. A new Proposed ADR under `docs/adr/4.x/` owns the charter redesign.
2. Living context, container, and component C4 views link to that ADR.
3. The active 4.x roadmap places Java reads under #645/4.x Work and later Java
   writes under #2519/CLI 4.x stable.
4. Architecture vision and any charter-domain plan contain pointers only.
5. No canonical page copies superseded projection-server conclusions.
6. The ADR distinguishes read conformance from write round-trip evidence.
7. The write gate includes a confined-mutation witness.
8. Unverified libraries, measurements, and adoption claims remain deferred.
9. Internal links, terminology, and Mermaid syntax validate.
10. Independent review returns no unresolved blocker about decision authority.
