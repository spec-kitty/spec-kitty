# Design decisions

Append-only notes for mission `approved-claim-bound-01M444QR`.

- 2026-10-04 (plan): refuse rather than drop the later commit (research.md R-1).
- 2026-10-04 (plan): the attestation is read by the same function as a real approval, so no voiding rule exists (R-6).
- 2026-10-04 (plan): on a mixed lane a canceled work package's latest stamp is a covered point, so existing closed-world verdicts are unchanged (R-4).
- 2026-10-04 (WP02): about thirty existing tests moved a lane after the fixture approved it; they were fixed with one restamp helper, not by weakening the rule.
- 2026-10-05 (WP04): a repeat attestation re-records only while the lane has not moved past the earlier one; the hollow-review check skips attestation events.
- 2026-10-05 (WP07): the check measures from the pre-mutation target tip, and other lanes' approval stamps are anchors; the mission branch is no longer a reference. Consequence: a commit inside another lane's approval stamp is not refused on its own lane.
- 2026-10-05 (WP07): orchestrator-api contract 1.10.0 for `data.preflight_error_code`.
- 2026-10-05 (#5720 rework): a canceled work package contributes no covered point; the commits inside its own closed, fully stamped work windows are exempt instead (any other event of it, and any attestation, covers nothing). A canceled-dependency refusal is not compounded with the mixed-lane refusals: an event-only line could differ from the next run's (first failing reason, rewritten lane, sibling-named refusals), so the limit is stated in the ADR and the contract instead.
- 2026-10-05 (#5720 second rework): the bound no longer defines a canceled work package's own commits. The exemption is the union of `Attributed.commits` from the claim's own mixed-lane attribution; an unattributable or never-implemented canceled work package contributes nothing, and `check_lane` reads no event of a canceled work package. The mixed lanes are resolved on a canceled-dependency refusal too, for that set only. Found while testing: two shapes the canceled-content checks pass (net-zero restore over an approved change; two canceled work packages cross-superseding), recorded as open in the ADR.
- 2026-10-05 (#5720 third rework, operator ruling): the exemption is dropped. Any content commit on a lane after its approval stamps refuses with `LANE_MOVED_AFTER_APPROVAL`, a canceled work package's own commit included; a mixed lane where a canceled work package worked after the approval needs the approved work package approved again. Reason: the covered-point, work-window and attribution-assigned exemptions each let a commit land unreviewed (last two shapes: a reopened canceled work package deleting an approved file as a net-zero restore; two canceled work packages superseding each other). The exemption threading in the claim builder is removed, and the mixed lanes are again not resolved on a canceled-dependency refusal.
