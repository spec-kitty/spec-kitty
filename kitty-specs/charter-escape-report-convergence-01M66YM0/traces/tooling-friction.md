- **[2026-10-30][planning] `spec-commit` refused the spec on local `main`, and the mission had no topic branch yet.** `spec-kitty specify` created the mission with `target_branch: main` because the checkout was on `main`, so `spec-commit` returned `PROTECTED_BRANCH_REFUSED` with "start a mission on a topic branch instead". Disposition: workaround — set the mission's `target_branch` to the topic branch in `meta.json` before the first commit. Candidate gap: `specify` could default to a topic branch (or `spec-commit` could accept the branch the operator is on) when the mission target is protected; #846's recovery text names `mission create --start-branch`, which cannot be used after the fact.
