# docs/development/testing/permission-denied-tests.md.

#   kernel-check     the test must exercise the real kernel permission check
#                    (a real stat through a locked directory, or a child

#                    an honest skip as root.

#                    same for every uid (a coverage diff of a uid-0 run against
